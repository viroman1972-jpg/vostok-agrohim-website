# Актуальный принятый макет главной страницы

**Текущая версия:** v19
**Принята:** 08.08.2026
**Автор реализации:** Claude Design
**Формат:** редактируемый экспорт `.dc.html`

## Что в директории

- **`Hero.dc.html`** — накопительный макет главной страницы. Содержит все семь принятых блоков подряд: Hero → Company Expertise → Задачи защиты → Каталог → Производители → Как мы работаем + CTA → Footer. Плюс cookie-баннер и плавающая кнопка «Наверх».

## Что не хранится в репо

- **`Hero-export.dc.html`, `vostok-agrohim-homepage.html`** — standalone-версии для просмотра в браузере без внешних зависимостей (изображения и скрипты inline base64). Тяжёлые (7–9 МБ), хранятся у заказчика локально.
- **`uploads/prod-*.png`** — изображения препаратов для карточек Каталога (Торнадо 540, Ордан, Борей Нео, Суховей). Сгенерированы через ChatGPT, служат плейсхолдерами до момента переноса в Tilda с реальными фото упаковок. Хранятся локально.
- **`uploads/avgust-dealer-letter-2026.jpg`** — скан дилерского письма АО Фирма «Август». В репо уже присутствует по пути `00-management/documents/avgust-dealer-letter-2026.jpg`. В `Hero.dc.html` путь до скана относительный (`uploads/avgust-dealer-letter-2026.jpg`) — сохраняется как есть на случай локального открытия макета.
- **`doc-page.js`, `support.js`** — служебные скрипты Claude Design. Локальные, не переносятся в Tilda.

## Регламент обновления

При каждой новой принятой итерации:
1. Скачиваем архив от Claude Design.
2. Копируем свежий `Hero.dc.html` в эту директорию, замещая старый.
3. Обновляем `Change log` в `homepage-structure-v2.md` и историю в `decisions-registry.md` с новой датой приёмки и версией макета.
4. При изменении структуры (не только контента) — обновляем `homepage-structure-v2.md` соответствующим bump'ом версии.

Snapshot прежних версий не сохраняется — актуальная версия достаточна как эталон принятой сборки. При необходимости откатиться — используем git history.

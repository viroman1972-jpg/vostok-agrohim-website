**Проект:** Редизайн сайта ООО «Восток АгроХим»

**Дата:** 20.08.2026
**Основание:** ОВ36 закрыт 20.08.2026 (тест механики разделов каталога Tilda) — см. `decisions-registry.md`, `phase-5-tilda/task-catalog-sections-test.md`, `phase-5-tilda/tilda-catalog-build-plan.md` (шаг 8).

---

## 1. Задача

Из 197 значений, получающих в Tilda собственные страницы разделов каталога (52 культуры + 68 вредных объектов + 64 ДВ + 7 категорий типов препаратов), отобрать 30–50 приоритетных значений для дополнительной ручной работы: создание «специальных страниц разделов» Tilda с уникальным контентом, мета-описанием, вводным SEO-текстом и, при необходимости, дополнительными блоками.

Остальные ~150 значений остаются на автогенерируемом шаблоне: свой slug (`/catalog/kultura/pshenitsa/`), автоматический `<title>` из названия раздела, сетка карточек товаров, стандартные фильтры. Этого достаточно для индексации и функциональной навигации; спецстраница нужна только там, где уникальный контент даёт заметный SEO- или конверсионный выигрыш.

---

## 2. Критерии отбора

Пять источников приоритета:

1. **Полнота навигации по типам препаратов.** Каталог из 6 категорий верхнего уровня + подраздел промышленных гербицидов (ДМ31, 30–40% продаж) — вся вертикаль. Ни одну не пропускаем.
2. **Универсальность значения.** Четыре категории сорняков (W001–W004) — привязаны почти ко всем гербицидам ассортимента и являются целью запроса «чем обработать двудольные сорняки на пшенице». Без спецстраницы для W001 сайт не отвечает на самый частый агрономический запрос по всему разделу гербицидов.
3. **Региональная сельхозспециализация.** Челябинская, Курганская, Свердловская, Тюменская области + сосед — Оренбург (лидер по подсолнечнику) и Башкирия (лидер по гречихе). Топ культур: пшеница яровая, ячмень яровой, овёс, гречиха, подсолнечник, рапс яровой, картофель, горох, лён масличный, многолетние травы, кукуруза на силос, свёкла сахарная.
4. **Число препаратов ассортимента по значению.** Действующие вещества, которые в каталоге представлены пятью и более препаратами, — очевидные центры притяжения для SEO. Тебуконазол — 9 препаратов, имидаклоприд — 7, 2,4-Д / клопиралид / феноксапроп-П-этил — по 5, глифосат — 3 (но с максимальной долей выручки за счёт промышленных гербицидов).
5. **Значимость болезни или вредителя для региона.** Септориоз, ржавчина, мучнистая роса — ключевые болезни зерновых Урала; фитофтороз — картофеля; колорадский жук — картофеля; клоп вредная черепашка — товарного зерна.

## 4. Что делает страницу «специальной»

Каждая спецстраница отличается от автогенерируемого раздела следующим:

- Собственное **мета-описание** (в автогенерируемом разделе `<meta description>` пустой; здесь пишется вручную под конкретный запрос).
- **Уникальный вводный текст** 300–800 знаков перед сеткой карточек — что это за категория / культура / ДВ / объект, для чего используется, региональная привязка.
- Для культур — короткая справка о сельскохозяйственной значимости в регионе, основных задачах защиты, рекомендуемых сроках обработок.
- Для ДВ — химический класс, механизм действия (HRAC/FRAC/IRAC), спектр применения, формы соли (для глифосата и МЦПА), особенности практического применения (антидоты для феноксапроп-П-этила и клодинафопа).
- Для сорняков/болезней/вредителей — краткое описание вреда, характерных признаков поражения, экономического порога.
- Для типов препаратов — сценарные быстрые входы (например, «Гербициды промышленные» → «Обочины дорог» / «Ж/д полотно» / «ЛЭП» / «Промзоны», по ДМ31).
- Уникальный **H1**, отличный от названия раздела в мегаменю.

Для остальных ~150 значений всё это генерируется автоматически из названия раздела — достаточно для индексации, но без уникального SEO-веса.

## 5. Оценка трудозатрат

- **Волна 1 (11 страниц):** 3–5 часов. Тексты для базовых категорий и сорняков — на основе уже согласованных SEO-текстов листингов (гербициды — v22 уже принят) и словаря вредных объектов v1.2.
- **Волна 2 (14 страниц):** 4–6 часов. Тексты по культурам — на основе региональных справочников и словаря культур v1.1; по ДВ — на основе словаря ДВ v1 (химкласс, МДА, продукты каталога уже расписаны).
- **Волна 3 (16 страниц):** 4–6 часов. Расширение по паттерну Волны 2.

**Итого:** 11–17 часов работы. Укладывается в диапазон шага 8 сборочного плана (`tilda-catalog-build-plan-part2.md` — 5–10 часов; при 41 странице ближе к верхней границе, ~13–15 часов, скорректируем при закрытии Волны 1).

## 6. Что осталось за рамками отбора и почему

**Не попали в приоритет** (обоснование по группам):

- **Дочерние формы культур с малой региональной значимостью:** C002 Пшеница озимая, C005 Ячмень озимый, C018 Рапс озимый, C008 Рожь озимая, C010/C011 Тритикале, C009 (родитель) — озимые в УрФО занимают ничтожную долю; трафик пойдёт на автогенерируемые страницы.
- **Родительские зонты с раскрытыми детьми:** C001 Пшеница, C004 Ячмень, C017 Рапс — трафик естественно распределится по спецстраницам детей (C003, C006, C019) + автогенерируемому родителю.
- **Плодовые и овощные:** C039 Яблоня, C039a Груша, C040 Виноград, C033 Капуста, C034 Морковь, C036 Лук, C036a Чеснок, C037 Томат, C038 Огурец, C038a Бахчевые — не профиль клиента (НР01, дачники исключены) и не главные культуры УрФО. Автогенерируемых страниц достаточно.
- **Спец. объекты:** C042 Пар, C043 Земли несельхозпользования, C044 Поля под посев — контент этих значений почти полностью покрыт спецстраницей «Гербициды промышленного применения» (T02).
- **Редкие ДВ с 1–2 препаратами:** ~40 позиций из словаря ДВ — генерируются автоматически, приоритетной работы не требуют.
- **Специфические болезни и вредители культур узкого сегмента:** пасмо льна (D026), крапчатость льна (D027), яблонная плодожорка (I025), гороховая зерновка (I027) и т.п. — трафик мал, покрываются автогенерацией.
- **ПАВ, антидоты, биопрепараты:** A1–A4, S1–S2, B1–B2 — либо не пестициды и без запросов, либо (Альбит) уже покрыты категорией «Стимуляторы роста».

**При появлении фактических данных Метрики** после запуска — состав приоритетных значений пересматривается: если по какому-то «непопавшему» значению виден заметный поисковый трафик на автогенерируемую страницу, оно попадает в следующую волну спецстраниц.

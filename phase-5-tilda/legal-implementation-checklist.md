# Чек-лист внедрения юридических требований (Phase 5, Tilda)

**Назначение:** обеспечить, чтобы ни одно решение из юридического аудита (пакет 19.08.2026, ДЗ04–ДЗ10, НР13–НР15, ОВ36–ОВ40) не потерялось при переходе от макетов к сборке сайта в Tilda и в дальнейшей эксплуатации.

**Как пользоваться:**
- Каждый пункт содержит: **что проверить**, **на каком этапе**, **где проверить**, **ссылку на решение реестра**.
- Проходить чек-лист последовательно на каждом этапе (миграция контента → сборка блока → перед публикацией страницы → перед запуском сайта → после запуска). Пометки: `☐` не проверено, `☑` проверено с датой.
- Для отложенных задач (ОВ40 — ежегодная пролонгация) вести отдельный календарь напоминаний.

## Этап A. Миграция контента (перед заливкой в Tilda)

### A.1. Контент-аудит по стоп-словам 109-ФЗ ст. 17 (ДЗ04)

**Стоп-слова, которые нужно найти и заменить/удалить:**
- `безопасн` — во всех формах (безопасен, безопасность, безопасное, безопасны)
- `безвредн`
- `нетоксичн`, `не токсичн`
- `экологически безопасн`, `экологически чист`, `экологичн`, `эко-`, `эко ` (с пробелом), `экочист`
- `биобезопасн`
- `щадящ` (щадящий, щадящее действие)
- `мягк.*препарат`, `мягк.*действ`, `мягк.*для`
- `натуральн` (в контексте препарата)
- `природн` (в контексте препарата, не механизма)
- `без вреда`, `без ущерб`, `без побочн`, `без последств`
- `не наносит вред`, `не вредит`
- `малоопасн`, `малотоксичн` — только вне классификационного контекста в скобках!
- Из 38-ФЗ ст. 5 ч. 3: `полностью защища`, `полн.*защит`, `100%`, `100 %`, `гарантир.*результат`, `гарантир.*эффект`, `гарантир.*защит`, `моментальн.*гибел`

**Разрешённые контексты (не заменять):**
- «Меры безопасности при работе» — название секции инструкции
- «Сроки безопасного выхода людей и техники на обработанные площади — N дней» — регламентный термин
- Цитата названия нормативного акта в кавычках (например, «СП 2.2.3670-20 „безопасность и (или) безвредность для человека факторов среды обитания“»)
- «Обезвредить сорбент раствором…» — процедура ликвидации разлива
- «3 класс — малоопасный» / «малотоксичен для пчёл» — перенос классификации из ГОСТ/госреестра в скобках

## Формат — что проверяем и с какими предположениями

По справке Tilda (`help-ru.tilda.cc/online-store/import-export`, сверено 17.08.2026):

- Разделитель CSV: **`;`** (точка с запятой)
- Внутри ячейки значения — через `;`, `,` или пробел
- Столбец `Category` — раздел товара, до 200 символов
- Столбцы английские: `Brand`, `SKU`, `Category`, `Title`, `Description`, `Text`, `Photo`, `Price`, `Quantity`, `SEO title`, `SEO descr`, `URL`, `External ID`

**Что справка НЕ говорит и что проверяется этим файлом:**

- **Как задать несколько разделов одному товару.** Гипотеза: перечислить их через `;` внутри поля Category (в кавычках, чтобы не сломать CSV). Если это не сработает — попробовать `,` или пробел без кавычек.
- **Как задать вложенность (родитель → ребёнок) через CSV.** В этом файле — **не задаётся**, все разделы плоские. Вложенность проверяется отдельно, в UI Tilda (перетаскиванием или через настройки раздела). Если по CSV нужна иерархия — тестируется вторым импортом с гипотезой ` > ` или `/`.
- **URL раздела: читаемый или служебный.** Смотрится после импорта в браузере.
- **Собственный slug раздела.** Пробуется задать в настройках раздела после импорта.
- **Мета-теги раздела.** Проверяются в исходном коде страницы раздела.
- **URL товара и `canonical`.** Товар в 14 разделах (Борей) — сколько адресов, что стоит `canonical`?

## Технические детали файла

- Кодировка: **UTF-8 с BOM** (для корректного открытия в Excel и Google Sheets)
- Разделитель: `;`
- Кавычки: минимальные (`csv.QUOTE_MINIMAL`) — только там, где значение содержит разделитель
- Перевод строк: `\n` (LF)
- Строка заголовков: одна, первая
- Пустые ячейки допускаются (`Quantity`, `SEO title` у части товаров)

## Известные ограничения выборки

- **Только фактические поля Tilda** — характеристики (`Characteristics:название`) не заполнены, добавятся отдельным столбцом при массовой загрузке
- **Фото — URL с satom.ru** — на тест сойдёт, для продакшена загружаются в CDN Tilda
- **SEO title/descr** заполнены только у Балерины — для теста, что происходит с пустыми
- **URL** — пробуем задать читаемый адрес (`/catalog/balerina-se/`); проверяем, соблюдает ли Tilda его

## Найденное при подготовке — не по теме теста, но фиксирую

**Лимит `Category` ≤ 200 символов может стать узким местом.** Из 8 тестовых товаров два подошли к пределу: Магнум — 160 символов, Торнадо — 192. У реальных карточек с 8+ культурами и 3+ ДВ (например, Борей Нео, Брейк, Шарпей — 15+ культур) лимит будет превышен. При импорте таких SKU либо надо резать список секций, либо использовать «характеристики» вместо разделов для дополнительных срезов. Уточнить после того, как убедимся, что раздел = страница со своим URL.

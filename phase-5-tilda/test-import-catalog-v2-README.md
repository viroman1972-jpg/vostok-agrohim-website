# Тестовый импорт каталога v2 — инструкция и справочник разделов

**Файл:** `phase-5-tilda/test-import-catalog-v2.csv`
**Дата:** 23.08.2026
**Основание:** результаты теста Tilda 20.08.2026 (см. `tilda-catalog-build-plan.md`, `task-catalog-sections-test.md`)

---

## 1. Что изменилось по сравнению с v1

Формат `Category` пересобран под подтверждённый в тесте механизм привязки товара к нескольким разделам:

- **v1:** мультизначения через `;` внутри двойных кавычек — тест 20.08 показал, что Tilda не парсит такой формат и молча игнорирует все привязки.
- **v2:** одна строка = одна связка «товар ↔ раздел». Товар с 11 разделами превращается в 11 строк с одинаковым `External ID` и разным `Category`. Tilda объединяет их в одну карточку по совпадению `External ID`.

**Итого:** 8 SKU × среднее 9 разделов = **72 строки данных**.

Все остальные поля (Title, Description, Photo, Price, URL и т.д.) продублированы в каждой строке. Дубли не создают дублей карточек — только дублируют связки.

## 2. Обязательные условия для успешного импорта

Установлены тестом 20.08. Без выполнения — импорт технически пройдёт, но результата не даст.

### 2.1. Разделы каталога созданы ДО импорта

Tilda не создаёт разделы на лету. Все 52 значения из колонки `Category` этого CSV должны существовать в каталоге до запуска импорта — иначе Tilda молча игнорирует несуществующие значения и товар остаётся без привязок.

Полный список — в разделе 5 этого файла.

### 2.2. Главная страница каталога назначена

Создать любую страницу с блоком каталога (например, шаблон ST300 с пустым блоком) и в «Настройки → Каталог товаров → Главная страница каталога» назначить её главной. Без этого адреса разделов не открываются вообще.

### 2.3. Валюта переключена на рубли

По умолчанию Tilda ставит доллары. Меняется в «Настройки сайта → Каталог товаров → Валюта».

### 2.4. Фото предзагружены в Tilda CDN

Ссылки в колонке `Photo` ведут на `images.satom.ru` — этот CDN блокирует запросы с IP Tilda (отдаёт 403). Ни одно фото по такой ссылке не подтянется.

**Решение:** до импорта загрузить 8 файлов из локальной папки `parsed_v2/photos/` в медиа-каталог Tilda через перетаскивание. После загрузки заменить ссылки в CSV на URL вида `https://static.tildacdn.com/tild.../filename.jpg`.

## 3. Кодировка и разделители

- Кодировка: **UTF-8 с BOM** (Tilda требует BOM для корректного чтения кириллицы; v2 сохранён с BOM).
- Разделитель полей: **точка с запятой `;`**.
- Обрамление строковых значений: **двойные кавычки `"..."`** — только там, где значение содержит `;` (в v2 не требуется, потому что каждая ячейка Category — одно значение).
- Перенос строк: **LF (`\n`)**.

## 4. Порядок действий для теста

1. Оплатить Personal или Business (Business даёт доступ к API — при массовом заведении разделов через скрипт это критично; для теста хватит Personal).
2. Настройки сайта → Подключаемые модули → включить «Каталог товаров» → сохранить.
3. Настройки каталога → сменить валюту на RUB.
4. Создать пустую страницу через шаблон ST300 (или любой другой с блоком каталога) → сохранить → в настройках каталога назначить её главной.
5. Каталог → Разделы → массово завести 52 раздела из раздела 5 этого файла (~30 сек/раздел = **25–30 минут**). Для каждого раздела: имя из колонки «Название», slug из «Slug». Иерархия для теста — плоская (без родительских разделов).
6. Медиа-каталог → перетащить 8 файлов фото из локального `parsed_v2/photos/`. После загрузки скопировать 8 URL из CDN Tilda.
7. Открыть `test-import-catalog-v2.csv` в текстовом редакторе (VS Code / Sublime) → массовой заменой заменить URL с `images.satom.ru` на URL из Tilda CDN. Сохранить.
8. Каталог → Ещё → Импортировать товары из CSV → выбрать файл → предпросмотр колонок → **Начать запись данных**.
9. Проверка результата — см. раздел 6.

**Ориентировочное время шагов 2–9:** 1,5–2 часа.

## 6. Чек-точки после импорта

1. **Количество товаров:** в каталоге 8 карточек (не 72). Если 72 — Tilda не поняла External ID и создала дубли; проверить формат идентификатора.
2. **Привязка к разделам:** открыть Балерину → блок «Разделы каталога» → должно быть 9 разделов (Гербициды, Пшеница, Кукуруза, Ячмень яровой, Овёс, 2,4-Д, Флорасулам, Однолетние двудольные, Многолетние двудольные). Аналогично для остальных 7 SKU по числу связок в v2.
3. **URL карточек:** открыть каждую из 8 карточек — URL должен соответствовать колонке `URL` CSV (например, `/catalog/balerina-se/`).
4. **URL разделов:** открыть `/catalog/gerbitsidy/`, `/catalog/pshenitsa/`, `/catalog/glifosat/`, `/catalog/odnoletnie-dvudolnye/` — во всех должны отображаться привязанные товары.
5. **Мета-теги:** SEO title и SEO descr подтянуты из соответствующих колонок CSV (проверить в исходном коде страницы).
6. **Валюта:** цены отображаются в рублях (например, 812 ₽ для Балерины).
7. **Фото:** подгрузились у всех 8 карточек (если предзагрузка через CDN Tilda прошла корректно на шаге 6 порядка).

## 7. Что делаем после успешного прогона

По результатам теста переходим ко второму шагу общего плана — осмотр автогенерируемых страниц разделов, проверка каталожных блоков, настройка фильтров. См. `tilda-catalog-build-plan.md`, шаги 6–8.

Если что-то из чек-точек 6 не сработало — фиксируем как открытый вопрос, ищем обходной путь до перехода к боевому импорту 87 SKU.

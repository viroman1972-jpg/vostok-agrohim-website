# Контент-план сайта Б

**Дата:** 09.07.2026
**Назначение:** сводный трек-план для этапа 4 (перенос контента). По каждой единице контента определён источник, ответственный, объём, приоритет.

## Обозначения

**Источник:**
- 🔵 **С сайта А** — переносится с адаптацией (структура и факты сохраняются, текст правится под новую подачу)
- 🟢 **С сайта А, без правок** — переносится как есть (типично для отзывов, дат, характеристик)
- 🟡 **Новый контент** — пишется заново на основе брифа персон и решений
- 🔴 **Внешний источник** — юрист / фото / логотипы производителей / реквизиты производителей

**Ответственный:**
- **К** — исполнитель (я, автор проекта — драфты, редактура, структура)
- **З** — заказчик (Восток АгроХим — фактические данные, фото, подтверждения)
- **Ю** — юрист (проверка правовых текстов)
- **К+З** — совместная работа

**Приоритет:**
- 🔥 Must-have для запуска (без этого сайт не может открыться)
- 🔸 Nice-to-have (можно добавить в первые 1–2 месяца после запуска)
- ⏳ Отложен на второй релиз

#### Представление «Для дачника»

**Пишется заново для каждого препарата.** Это уникальный контент, которого не было ни на сайте А, ни у конкурентов.

| Блок | Источник | Ответ. | Приоритет |
|---|---|---|---|
| Простое описание («Это препарат для…») | 🟡 Новый (из агрономических данных) | К | 🔥 |
| Регламент по-дачному (мл/на 10 л воды / на сотку) | 🟡 Пересчёт из л/га | К+З (сверка) | 🔥 |
| Как разводить и применять (пошагово) | 🟡 Новый | К | 🔥 |
| Меры безопасности (простой язык) | 🟡 Из первой помощи, но переписано | К | 🔥 |
| Когда обрабатывать (фазы, время суток) | 🟡 Новый (из агрономического регламента) | К | 🔥 |

**Формула пересчёта:** для каждого препарата — если норма 0,3 л/га, то на сотку = 0,3 / 100 × 10 000 / 10 000 = 0,03 л/сотку = 30 мл/сотку в 10 л воды. Формула фиксированная, но для каждого препарата нужна ручная сверка (не все препараты применяются на сотку — некоторые только промышленно; такие препараты в дачном представлении помечаются как «Не рекомендуется для ЛПХ»).

**Оценка объёма:** ~91 карточка × 800–1200 знаков дачного текста = **~80 000–110 000 знаков** нового текста. Это порядка **5–7 полных рабочих дней автора**.

**Стратегия:** написать первые 5–10 карточек как эталон, показать заказчику для сверки, потом остальные 80 по шаблону.

**Что не пишем в дачном представлении:** препараты, которые в принципе не для ЛПХ (например, авиахимобработка сельхозугодий, промышленные протравители зерна). Для таких карточек — блок «Не рекомендован для дачи», кнопка «Позвонить агроному» ведёт напрямую к директору.

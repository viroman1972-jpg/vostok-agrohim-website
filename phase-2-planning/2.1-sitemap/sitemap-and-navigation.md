## Уровень 1: главные страницы

### / — Главная

**Назначение.** Основной вход. Первый экран говорит с фермером (основная персона), но даёт явное разделение на «Опт» и «Для дачи».

**Ключевые блоки первого экрана (согласовано в брифе 1.5):**
- H1: «Оптовый поставщик СЗР и агрохимии по всей России. Работаем с 2011 года — прямо с директором.»
- Подзаголовок: «Средства защиты растений от Август, Байер, БАСФ, Щёлково Агрохим, ФМРус и других — со склада в Челябинске и с доставкой ТК по РФ.»
- CTA: «Написать директору» (модальное окно с Telegram / MAX / звонок / форма) + «Открыть каталог» + «Скачать прайс».
- Пруф-блок под первым экраном: 15+ лет, 91+ SKU, работаем со всеми формами клиентов, прямые контракты с производителями.
- Явный переключатель «Я оптовый / Я дачник» под первым экраном.

**Дальнейшие блоки:**
- Категории каталога (7 плиток по типам препаратов).
- Каталог по культурам (плитки: пшеница, ячмень, кукуруза, подсолнечник, соя, рапс — топ-6).
- Хиты продаж (5–8 SKU).
- Блок «Наши партнёры-производители» (логотипы).
- Блок «Работаем с любыми объёмами» — с ссылкой на «Опт» и «Дачу».
- Отзывы (6 существующих + карусель) с CTA «Оставить свой».
- Блок «Прямая связь с директором» — фото, имя, короткая цитата, кнопки Telegram/MAX/звонок.
- Полезные материалы (превью 3–4 статей из блога).
- Футер (см. раздел «Навигация»).

### /catalog — Каталог (базовый вход по типу препарата)

**Назначение.** Каталог как единая товарная витрина. Базовый вход — по типу препарата (унаследовано с сайта А).

**Устройство страницы:**
- Верх: переключатель между 4 срезами — [По типу препарата] [По культурам] [По вредным объектам] [По действующим веществам]. Переключение — переход на соответствующий URL.
- Плитки категорий (7 типов препаратов) с иконками и количеством товаров.
- Под плитками — общий листинг всех товаров с фильтрами (культура + вредный объект + д. в. + упаковка + производитель + бинарный флаг «Доставка ТК / Только самовывоз»).
- Кнопка «Скачать прайс-лист».

### /catalog/crops — Каталог по культурам

**Назначение.** Второй вход в каталог — «от задачи». Персона Николая Александровича (фермер) идёт именно сюда.

**Структура:** плитка каждой культуры с иллюстрацией. Внутри культуры — фильтр по вредным объектам этой культуры + список подходящих товаров.

### /catalog/pests — Каталог по вредным объектам

**Назначение.** Персона Алевтины Викторовны (дачник) идёт сюда: «у меня плодожорка — что делать?». Также используется опытными агрономами.

**Структура:** три подраздела — Сорняки / Вредители / Болезни. В каждом — плитки конкретных объектов (Пырей, Осот, Тля, Плодожорка, Фузариоз и т. д.). Внутри — список товаров.

### /catalog/ingredients — Каталог по действующим веществам

**Назначение.** Персона Ивана Петровича (агроном крупного хозяйства) идёт сюда: «нужен продукт с флорасуламом 25 г/л».

**Структура:** алфавитный список действующих веществ с фильтром по группам и по типу препарата. Внутри — список товаров с этим веществом.

### /catalog/product/{slug} — Карточка товара

**Назначение.** Основная конверсионная страница. ~91 карточка.

**Устройство:**
- Хлебные крошки (Главная → Каталог → Категория → Товар).
- Название H1 с концентрацией действующего вещества.
- **Переключатель «Для агронома» / «Для дачника»** (решение 09.07.2026) — в верхней части карточки.
- Медиа (галерея упаковок).
- Цена + бинарный бейдж доставки («Доставка ТК» / «Только самовывоз») + статус наличия + CTA «Купить» / «Заказать» / «Написать директору».
- Sticky-CTA справа (десктоп) / внизу (мобайл).
- 15+ блоков карточки по анатомии из 1.1 (характеристики, регламент применения, первая помощь, безопасность и т. д.) — в двух представлениях: агрономическом и дачном.
- Форма запроса SDS (модальное окно).
- Форма запроса консультации по препарату (модальное окно).
- Оптовые скидки шкалой (для B2B).
- Похожие товары.
- **С 01.09.2026:** ссылка на реестр сертификатов / декларации.

### /opt — Опт / Для дистрибьюторов

**Назначение.** Персона Сергея Валерьевича (дистрибьютор). Устраняет возражение «сайт не рассчитан на нас».

**Блоки:**
- Первый экран: «Оптовые поставки для дистрибьюторов, КФХ, агрохолдингов».
- «Для кого мы работаем оптом» — 4 сегмента (дистрибьюторы, КФХ от 100 га, агрохолдинги, тепличные комплексы).
- «Условия оптового сотрудничества» — минимальный объём, шкала скидок, отсрочка платежа, порядок работы с постоянными клиентами.
- «Документооборот» — какие документы предоставляем (договор, УПД, счёт-фактура, ТОРГ-12, сертификаты), «работаем с НДС».
- «Как начать работать с нами» — 4 шага (заявка → согласование условий → пробная поставка → долгосрочный контракт).
- Прайс-лист (кнопка скачивания).
- CTA «Обсудить условия с директором».
- Реквизиты компании (полный блок).

### /dacha — Для дачи и малых хозяйств

**Назначение.** Персона Алевтины Викторовны (дачник, ЛПХ). Устраняет возражение «здесь всё промышленное, не для меня».

**Блоки:**
- Первый экран: «Средства защиты растений для вашей дачи и небольшого хозяйства».
- «Работаем с любыми объёмами» — от 1 флакона.
- «Простые инструкции» — в каждой карточке есть представление «Для дачника».
- «Помощь в подборе» — CTA «Опишите проблему в двух словах — подберём препарат» (форма, ведёт к директору).
- Топ-препараты для дачи (плитки).
- Каталог по типовым дачным задачам (Тля / Плодожорка / Мучнистая роса / Сорняки на грядках / Фитофтора).
- Отзывы дачников (если есть) или блок «Спросите директора».
- «Как получить свой заказ» — самовывоз в Челябинске / доставка ТК / (возможно) отправка Почтой России.
- CTA «Написать директору».

### /about — О компании

**Блоки:**
- Первый экран: «ООО „Восток АгроХим" — оптовый поставщик СЗР с 2011 года».
- «Наша история» — короткий текст (не «вода», а факты: год основания, регионы работы, партнёры).
- «Кто мы» — фото и имя директора, короткое обращение от первого лица. Модель моно-контакта как преимущество.
- Логотипы производителей-партнёров.
- Регионы, куда отгружаем (карта РФ с точками или без).
- «Наши клиенты» — при возможности логотипы / короткие кейсы.
- Реквизиты (полный блок).
- Позиция по 152-ФЗ и работе с ПДн (реестр операторов ПДн № 74-22-014520 от 28.11.2022).
- CTA «Связаться».

### /delivery — Доставка и оплата

**Блоки:**
- «Как получить заказ»: (1) самовывоз со склада в Челябинске + адрес, время работы; (2) доставка ТК по РФ.
- «Транспортные компании» — «Работаем с любой ТК по вашему выбору. Рекомендуем ПЭК и КИТ — у них лучшая упаковка для наших грузов».
- **«Условия доставки»** — часть препаратов относится к опасным грузам с ограничениями на перевозку ТК; такие препараты отправляются только самовывозом. Индикатор на карточке.
- «Паспорт безопасности» — SDS выдаётся по запросу через форму на карточке.
- «Оплата» — способы (безнал по счёту, при получении, при возможности — картой онлайн).
- «Работа с юрлицами и НДС» — полный пакет закрывающих документов.

### /warranty — Гарантии и претензии

**Блоки:**
- «Наши гарантии» — оригинальность препаратов, соответствие сертификатам, документы на каждую партию.
- «Что делать при проблеме» — короткая инструкция.
- **«За решение спорных ситуаций отвечает лично директор — Прутян Андрей Владимирович»** — сильная формулировка (усиление УТП моно-контакта).
- Форма претензии (модальное окно) — попадает директору с высоким приоритетом.
- Ссылка на «Правила возврата».

### /documents — Документы и сертификаты

**Назначение.** Персона Сергея Валерьевича (дистрибьютор) идёт сюда за подтверждением серьёзности. Также — соответствие требованию 01.09.2026 (ссылка на реестр сертификатов из карточки товара).

**Блоки:**
- «Документы компании» — свидетельство о регистрации, реквизиты (со ссылкой на /about), запись в реестре операторов ПДн.
- «Сертификаты и декларации на препараты» — таблица или картотека: препарат → номер сертификата → ссылка на реестр РФ/ЕАЭС.
- «Образцы документов при отгрузке» — договор поставки, УПД, ТОРГ-12, счёт-фактура (иконки, при клике — образцы).
- «Паспорта безопасности (SDS)» — форма запроса.

### /blog — Полезные материалы

**Назначение.** SEO + помощь клиенту. 4 существующие статьи с сайта А + новые.

**Устройство:** список статей с превью, категориями, датой. Каждая статья — с формой подписки на новые материалы (опционально, если решим делать email-рассылку).

### /contacts — Контакты

**Блоки:**
- Все контакты: телефон (кликабельный), email, Telegram, MAX.

## Модальные формы (не отдельные URL)

- **Форма заявки** — с любой страницы через кнопку CTA. Поля: имя, телефон, email (опц.), сообщение, чекбокс согласия.
- **Форма запроса SDS** — с карточки товара. Поля: препарат (заполнен), email, чекбокс согласия.
- **Форма претензии** — с /warranty. Поля: ФИО, контакты, номер заказа (опц.), суть претензии, чекбокс согласия.
- **Форма запроса консультации** — с карточки товара. Поля: препарат (заполнен), вопрос, контакт, чекбокс согласия.
- **Форма «Написать директору»** — универсальный CTA. Открывает модалку с выбором канала: Telegram / MAX / звонок / оставить сообщение.
- **Форма отзыва** — на /warranty или на отдельной странице /reviews (обсудим отдельно). Возможна отправка через 2 недели после отгрузки email-триггером.
- **Форма подписки** — в футере (опционально, если решим делать рассылки).

Все формы:
- С чекбоксом согласия на ПДн (отдельная ссылка на Политику).
- Отдельный чекбокс для рекламной подписки (если применимо).
- Логируют согласия в БД (дата, время, IP, версия документа).

## Логика навигации

### Шапка (Header)

**Десктоп:**
```
[Логотип] [Каталог ▼] [Опт] [Для дачи] [О компании] [Доставка] [Контакты]     [🔍] [📞 +7 351 750-09-20] [Telegram +7 922...] [MAX +7 922...]
```

Логика телефонов:
- **+7 (351) 750-09-20** — офисный, для звонков (переход в приложение звонка на мобильных).
- **+7 (922) 750-09-20** — мобильный директора для Telegram и MAX (ссылки `t.me/+79227500920` и аналогично для MAX). На него можно и позвонить в неурочное время / когда офис недоступен.

На карточках товара и в CTA-блоках — оба номера с явными подписями («Позвонить в офис» / «Написать директору в Telegram»).

Выпадающее меню каталога (в hover):
- По типу препарата → ссылки на 7 категорий
- По культурам → 12 подкатегорий
- По вредным объектам → 3 (сорняки/вредители/болезни)
- По действующим веществам → отдельная страница

**Мобайл:**
```
[Логотип]                            [🔍] [📞] [☰]
```
Гамбургер разворачивается в полноэкранное меню со всеми пунктами.

**Sticky при скролле:** упрощённый вариант с логотипом + кнопкой «Написать директору».

### Футер

Пять колонок (десктоп) / раскрывающиеся аккордеоны (мобайл):

1. **О компании** — О нас, Партнёры, Реквизиты, Отзывы, Блог.
2. **Каталог** — По типу препарата, По культурам, По вредным объектам, По д. в., Скачать прайс.
3. **Клиентам** — Опт, Для дачи, Доставка, Оплата, Гарантии, Документы, FAQ.
4. **Правовое** — Политика ПДн, Согласие, Оферта, Соглашение, Cookies, Возврат.

## URL-структура — принципы

- **Транслитерация** для человекочитаемых URL: `/catalog/gerbicidy`, а не `/catalog/herbicides` (SEO для русскоязычного поиска).
- **Иерархия отражает структуру каталога:** `/catalog/{тип}/{товар}` для товаров, `/catalog/crops/{культура}` для категорий по культурам.
- **Slug товара** = транслитерация названия + суффикс (концентрация): `boreye-sk-150-50`.
- **Никаких query-параметров** в основных URL — только для фильтров.
- **Все URL — в нижнем регистре**, без пробелов и подчёркиваний (дефис-разделитель).

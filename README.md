# Проект: Редизайн сайта Восток Агрохим

Миграция действующего корпоративного сайта **vostok-agrohim.ru** (сайт А) на новый сайт (сайт Б) на платформе **Tilda** (тариф Personal).

## Ключевые принципы

1. **Ничто не теряется** — вся информация с сайта А переносится на сайт Б.
2. **Что-то добавляется** — если это требует закон или если это повышает продажи.
3. **Дизайн и UX по трендам 2025–2026**.
4. **Соответствие законодательству РФ** — с явными ссылками на НПА.
5. **Пофазная сдача** — каждый следующий пункт плана начинается после согласования результата предыдущего.

## Структура репозитория

| Папка | Содержание |
|---|---|
| `00-management/` | План проекта, журнал решений, статус |
| `phase-1-analysis/` | Этап 1: анализ (сайт А, конкуренты, отзывы, право, ЦА) |
| `phase-2-planning/` | Этап 2: карта сайта, user flows, контент-план |
| `phase-3-design/` | Этап 3: mood board, design system, прототипы |
| `phase-4-content/` | Этап 4: тексты страниц, правовые тексты, медиа-план |
| `phase-5-tilda/` | Этап 5: реализация на Tilda (настройки, страницы, интеграции) |
| `phase-6-legal-audit/` | Этап 6: предзапусковый правовой аудит |
| `phase-7-testing/` | Этап 7: тестирование |
| `phase-8-launch/` | Этап 8: запуск и редиректы |
| `phase-9-maintenance/` | Этап 9: регламент сопровождения |
| `phase-10-github/` | Этап 10: финализация репозитория |

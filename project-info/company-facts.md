# Общая информация о компании

Тип бизнеса:

# Основное направление деятельности

Основная специализация:

- средства защиты растений (СЗР);
- препараты для защиты сельскохозяйственных культур.

Важно:

Компания НЕ продает удобрения.

Не использовать формулировки:

❌ «удобрения и средства защиты растений»

Корректные формулировки:

✅ «средства защиты растений»
✅ «препараты для защиты сельскохозяйственных культур»
✅ «решения в области защиты растений»

Компания:

- небольшая региональная;

Важно:

Не создавать образ крупной федеральной корпорации.

Главные преимущества:

- знание продукта;
- индивидуальный подход.

- надежность;

- ответственность.

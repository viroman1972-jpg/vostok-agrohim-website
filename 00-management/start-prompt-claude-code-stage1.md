# Стартовый запрос для Claude Code (после среза 1)

Составлен 19.10.2026. Основание: НР18 (сборку и сопровождение ведёт Claude Code).

## Что сделать перед запуском

1. Загрузить в репозиторий картинки и шрифты (через веб-интерфейс GitHub, по одной папке):
   - `site/static/fonts` — 14 файлов
   - `site/static/img/products` — 8 файлов
   - `site/static/img/home` — 7 файлов
2. Иметь на компьютере копию репозитория.
3. Положить в `design-reference/` (вне git) три макета: главная, список гербицидов, карточка Балерины.
4. Открыть Claude Code в папке репозитория и вставить запрос ниже.

## Запрос

Прочитай `00-management/status.md` и `CLAUDE.md`. Срез 1 уже в `main`: главная, список гербицидов, карточка Балерины, сборка в `scripts/build.py`, проверки в `scripts/check.py`. Соберите сайт, запустите проверки и сверьте результат с макетами в `design-reference/`. Затем выполни этап «Тестовый сайт на хостинге» из `work-plan-selfbuilt-v1.md`. Остальные страницы и загрузку каталога начинай только после моего согласования.

- До загрузки картинок и шрифтов сборка и проверки будут ругаться на отсутствующие файлы.

- Обработчик заявок `/send.php` не написан (форма отправляет на него).
- Telegram и MAX в подвале не выводятся (ДМ35, НР17). Щёлково не упоминается (НР05). Ссылка на дилерское письмо убрана до нового письма (ОВ40, до 15.12.2026).

- Срез залит сразу в `main`; по `CLAUDE.md` правки идут сначала в `staging` — создать ветку при настройке выкладки.

## 2. Схема данных

```
data/products.csv    строка = SKU. Правит Оля с Claude.
data/prices.csv      slug, price, unit, status(published|archived). Правит заказчик.
data/settings.yml    телефоны, график, реквизиты, почта. Правит заказчик.
data/dict/*.csv      categories, manufacturers, forms, countries, tags, crops (52),
                     pests (68, с подтипом), substances (64, с химклассом), series
data/links/*.csv     product_crop, product_pest, product_substance, cross_sell (ДМ29)
content/products/<slug>/*.md   регламент, первая помощь, вкладки
content/seo/*.md     тексты категорий, культур, объектов, ДВ
content/pages/*.md   about, contacts, comments, privacy-policy
```

### products.csv: поля (по catalog-ia §4)

| Группа | Поля |
|---|---|
| Идентификация | `slug`, `name`, `category`, `manufacturers` (список), `country`, `form` |
| Классификация | `substances` (список, из links), `drug_type`, `action_on_organism`, `action_character`, `functional_subtype` |
| Применение | `application_methods`, `application_term`, `tags` (`desikaciya`, `promyshlennoe-primenenie`) |
| 7 характеристик карточки | действующее вещество, форма препарата, тип применения, способ проникновения, класс опасности для человека, класс опасности для пчёл, фитотоксичность |
| Безопасность и доставка | `delivery_flag` (`TK_RF` / `SAMOVYVOZ_ONLY`), `restrictions`, `wholesale_only` |
| Упаковка | `package_type`, `package_sizes`, `unit`, `min_order`, `storage_conditions`, `shelf_life` (из госреестра, ПИ10) |
| Медиа и SEO | `photo`, `photo_back`, `meta_title`, `meta_description`, `description` |
| Служебное, не публикуется | `status` (draft/published/archived), `registration_type`, `registration_expiry` (алерт при сроке менее 90 дней, ОВ15), `notes`, `updated` |

Не хранятся и не публикуются: регистрационный номер, дата свидетельства, класс ДОПОГ (решение Прутяна А.В. 24.08.2026). Поле «наличие» отсутствует (ПИ11).

Цена в `products.csv` не хранится, только в `prices.csv` (П10, раздел 2.3 плана).

## 3. Цены (план, 2.3)

Генератор берёт цену из `prices.csv` и вставляет её в карточку, листинги, блок «Смотрите также» и разметку `Offer`. Сборка падает, если у опубликованного препарата нет цены. Проверка: цена в видимом тексте равна цене в разметке.

## 4. Что считается страницей-оболочкой, пока нет макетов

Меню «Задачи защиты», «Как мы работаем», «Производители» (ДМ34): неизвестно, это отдельные страницы или блоки главной. Решается по актуальным макетам на этапе среза.

## 5. Отличия от прежних документов (нужно согласие Оли)

1. **Фильтры листинга** (catalog-ia §8: адрес вида `?substance=glifosat`). На статичном сайте такие адреса не создаются заранее. Предлагаю: фильтры работают в браузере и обновляют адрес; для поиска существуют страницы входов `/catalog/dv/`, `/catalog/kultura/`, `/catalog/vrednyy-obekt/`. Это не теряет SEO, ради которого вводился параметр.
2. **Десиканты.** В `CLAUDE.md` стояло «не категория, а тег». Исправлено по `catalog-ia-v1.md` v1.7 и ПИ08: это седьмая категория со своим адресом, содержимое которой строится по тегу.
3. **Пагинация** по 12 карточек: адреса `/catalog/{категория}/?page=2` не индексируются; все карточки доступны и на `/catalog/all/` с режимом «показать всё».
4. **Поиск по каталогу** (§9): индекс собирается при сборке, поиск работает в браузере без внешних сервисов.

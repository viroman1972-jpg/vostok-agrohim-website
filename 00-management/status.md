## Часто путаемое (памятка, не исчерпывающий список)

**По контенту:**

- **/opt, /dacha** — отдельных лендингов НЕТ.
- **Отдельных маркетинговых лендингов по типам препаратов** (Пестициды/Гербициды/Инсектициды/…) НЕТ. По типам есть только листинги каталога.
- **Telegram-бот, рекомендатель препаратов** — НЕТ (НР12).
- **Отдельные формы «Заказать звонок» / «Прайс» / «Задать вопрос»** — НЕТ. Единая модальная форма (ДМ30).
- **Ссылка `/opt` в футере** — НЕТ (НР13).
- **Формулировка «Прямые дистрибьюторы»** — не использовать (риск по 38-ФЗ).
- **Макеты в репо не хранятся** — только у Оли локально и в Claude Design.
- **Состав блока «Характеристики» карточки товара — 7 полей** (решение Прутяна А.В., 24.08.2026): действующее вещество, форма препарата, тип применения, способ проникновения, класс опасности для человека, класс опасности для пчёл, фитотоксичность. **НЕ показываем:** регистрационный номер, дата свидетельства о регистрации, класс ДОПОГ. Файл `phase-5-tilda/balerina-card-tabs.html` пока содержит все 10 — при следующем обновлении привести к 7 в шапке характеристик (сами вкладки не трогать, там этих полей нет).
- **SEO-тексты — только по регламенту.** Никаких экстраполяций свойств препаратов, никаких конкретных чисел (нормы, фазы, дни, температуры), никаких международных комитетов (FRAC/IRAC) без запроса. Названия торговых препаратов — только реально в ассортименте; при сомнениях — сверка с Прутяном А.В. Полный свод правил — в шапках `phase-4-content/wave-1-seo-texts.md`, `wave-2-dv-seo-texts.md`, `wave-2-cultures-seo-texts.md`, `wave-3-vrednye-obekty-seo-texts.md`, `wave-3-cultures-seo-texts.md`, `wave-3-dv-seo-texts.md`.
- **Правило 4 для страниц вредных объектов, культур и ДВ** (зафиксировано в шапках файлов Волны 3): препарат в поимённом перечне — только при подтверждённой связке препарат → культура → конкретный объект / препарат → культура / препарат содержит ДВ. Общая регистрация «на пшенице» / «на картофеле» или общая известность препарата в отрасли — недостаточное основание. Принцип «если сомневаюсь — не пишу»: формулировки, не сверенные по регламенту, просто опускаются, а не выносятся под флаг.
- **Проверенные фактологические уточнения по препаратам** (из правок Волны 3): **Гамбит** — на основе прометрина (не пропизохлора), зарегистрирован на кукурузе; **Парадокс** (имазамокс) — на сое без требования устойчивости сорта к имидазолинонам, на люцерне с делением по возрасту посевов, на рапсе и подсолнечнике — только на устойчивых к имидазолинонам сортах/гибридах; **Дублон Голд** — контролирует не только злаковые, но также однолетние и некоторые многолетние двудольные сорняки на кукурузе; **Горгон** — на основе МЦПА и пиклорама, применяется на землях несельскохозяйственного назначения против борщевика Сосновского и злостных двудольных сорняков.
- **Меридиан, ВР** — по товарной выгрузке от 29.07.2026: клопиралид 267 г/л + пиклорам 67 г/л, производитель Гарант Оптима. Клопиралидный статус подтверждён (открытый флаг в wave-2 DV021 можно снять). Пиклорамный статус по регламенту agroxxi не подтверждён — Меридиан НЕ включён в wave-3 DV034 Пиклорам (регламент приоритетнее выгрузки).
- **Связка препарат ↔ сортовая устойчивость** — всегда сверяется на конкретной культуре, не переносится по аналогии между культурами.
- **Терминология посевного материала — по культуре точно.** Соя — сорт; кукуруза — гибрид (в основном); свёкла сахарная — гибрид; рапс, подсолнечник — сорта и гибриды.
- **Технологические названия — точно, как у правообладателя.** CONVISO® SMART (для свёклы), SMART-гибриды — не «Conviso Smart». Аналогично Clearfield® и др.
- **Аббревиатуры ферментов в описании механизмов действия** (согласовано в wave-3-dv): для ALS-ингибиторов — «ингибиторы ацетолактатсинтазы (ALS)»; для ACCase-ингибиторов (граминициды) — «ингибиторы ацетил-КоА-карбоксилазы (ACCase)»; для триазолов — «ингибиторы деметилирования (DMI): подавляет фермент 14α-деметилазу (CYP51)». Для механизмов, действующих на нервную систему (пиретроиды, неоникотиноиды), — без аббревиатур: «воздействует на натриевые каналы нервных клеток насекомых».

**По платформе:**

- **Tilda — не наш выбор** (НР16, 24.08.2026). Причины: (а) визуальный редактор карточки товара экранирует HTML на публичной странице во всех типах вкладок; (б) параметрические URL разделов, не ЧПУ. Все артефакты `phase-5-tilda/*` в репо — исторические, при выборе новой платформы переоцениваются.
- **Кандидат №1 для пилота — Craftum**; резерв — InSales (см. ОВ42). WordPress+WooCommerce требует разработчика и по критериям заказчика (Оля одна, без разработчика) не проходит; оставлен на случай, если конструкторы окажутся тесны.
- **Что переносимо на любую новую платформу без потерь:** SEO-тексты 3 волн, parsed_v2 (парс satom по 92 SKU + фото), макеты, схема данных, словари категорий/разделов, все принципы контента, юридический чек-лист.

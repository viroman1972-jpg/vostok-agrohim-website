# Сравнение хостингов для сайта — v1 (выбран Timeweb, 21.10.2026)

**Дата:** 20.10.2026. **Основание:** план работ §2.4, этап 0 п. 6. Финальный выбор — после ответа заказчика на К2 (оформление на ООО, оплата от компании).

Цены — с официальных страниц тарифов на 20.10.2026, за месяц при оплате за год; перед оплатой сверить. «Уточнить» — на странице тарифов не сказано, спросить в поддержке до оплаты.

| Критерий (§2.4) | Beget | Timeweb | REG.RU |
|---|---|---|---|
| Младший подходящий тариф | Blog — 420 ₽/мес (5 040 ₽/год), 5 сайтов | Year — 316 ₽/мес, 2 сайта; Optimo — 510 ₽/мес, 15 сайтов | Host-0 — 420 ₽/мес (5 038 ₽/год), 7 сайтов |
| SSH/SFTP для автовыкладки | есть на всех тарифах | есть, включается в панели | уточнить |
| `.htaccess` (301-редиректы, пароль на тест) | уточнить (Apache обычно есть) | есть | уточнить |
| PHP для скрипта заявок | есть | есть (до 8.4) | есть |
| Почта на домене | есть | есть, без ограничения ящиков | есть |
| Управление DNS (SPF/DKIM/DMARC) | уточнить | есть | есть (регистратор домена) |
| Бесплатный SSL с автопродлением | есть | Let's Encrypt | Let's Encrypt или GlobalSign |
| Договор с ООО, безнал, документы | уточнить | есть: договор, безнал, ЭДО | уточнить |

Всем трём хватает младшего тарифа: сайт статичный, ~300 страниц и фото.

**Рекомендация:** Timeweb (Optimo, если понадобится больше 2 сайтов; на старте хватит Year: боевой сайт + тестовый поддомен — уточнить, считается ли поддомен отдельным сайтом). На официальной странице подтверждены все критерии, кроме SSH, а SSH подтверждён в документации. Запасной вариант — Beget. REG.RU удобен, если имя сайта уже зарегистрировано там (ответ на К1), — тогда домен и хостинг в одном кабинете; но SSH и `.htaccess` у него надо подтвердить.

**Что нужно от Оли после выбора** (для выкладки на тест):
1. Создать поддомен для тестовой копии (например `test.vostok-agrohim.ru`) — DNS имени сайта меняется только для поддомена, старый сайт на Satom не затрагивается.
2. Включить SSH, создать ключ выкладки; файл паролей тестовой копии положить на хостинге вне папки сайта.
3. Внести секреты в GitHub (Settings → Secrets → Actions): `STAGING_SSH_KEY`, `STAGING_SSH_HOST`, `STAGING_SSH_USER`, `STAGING_SSH_PATH`, `STAGING_SSH_KNOWN_HOSTS`, `STAGING_HTPASSWD_PATH`. Сами значения в чат и в репозиторий не передавать.

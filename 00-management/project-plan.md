## Этап 5. Реализация на Tilda

**Оценка трудозатрат** (уточнено 20.08.2026 по итогам теста механики разделов каталога Tilda на trial-аккаунте Personal — см. `phase-5-tilda/task-catalog-sections-test.md`):

- **~50 страниц ручной сборки:** главная, служебные страницы (О компании, Контакты, Политика ПД, /comments/, /price/, /about/, карта сайта), 30–50 приоритетных «спецстраниц разделов» с уникальным контентом и мета (перечень — `phase-5-tilda/priority-sections-list.md`), шаблоны листинга и карточки товара.
- **~140 автогенерируемых страниц разделов каталога** (остаток от 190 значений словарей: 52 культуры + 68 вредных объектов + 64 ДВ + 7 типов препаратов) — заводятся административной операцией внутри Tilda, ~30 сек на раздел = ~1,5–2 часа разовой работы.
- **43–64 часа админской работы по каталогу и сборке.** Детализация по шагам (создание разделов, загрузка фото в CDN, генерация и импорт CSV, шаблоны, спецстраницы, формы, аналитика, редиректы, тестирование) — в `phase-5-tilda/tilda-catalog-build-plan.md` §5.
- При параллельной работе (админка каталога + вёрстка шаблонов) — 4–5 рабочих дней; при последовательной с одним исполнителем — 6–8 рабочих дней.

Прежняя предположительная оценка «105–400 страниц» из `site-pages-inventory.md` §5 заменена подтверждённой.

- **5.1.** Создание проекта на Tilda, базовые настройки. Требует оплаченного аккаунта клиента (Personal ~750 ₽/мес, рекомендуется Business ~1250 ₽/мес — доступ к API для скриптовой правки slug'ов 190 разделов).
- **5.2.** Сборка страниц. Разделена на три подэтапа: (а) заведение 190 разделов каталога с человекочитаемыми slug'ами и иерархией; (б) загрузка 117 уникальных фото упаковок в CDN Tilda + генерация и импорт боевого CSV на 87 SKU (многострочный формат, ~700 строк по одной на связку «товар — раздел»); (в) вёрстка Zero Block'ов — карточка товара, листинг категории, главная каталога, главная сайта, служебные страницы, 30–50 спецстраниц приоритетных разделов.
- **5.3.** Настройка форм с корректной обработкой ПДн (по ТЗ из 4.4 и с учётом ДЗ07 — отдельный чекбокс согласия с указанием цели, без атрибута `checked`).
- **5.4.** Интеграции: встроенные «Заявки» Tilda + Telegram + MAX + Google Sheet по ДМ04. Внешняя CRM — не в первом релизе (НР11).
- **5.5.** SEO: мета для главной, служебных, спецстраниц приоритетных разделов; sitemap.xml; robots.txt; микроразметка BreadcrumbList (уже в макете листинга) + ItemList/CollectionPage (ДМ33).
- **5.6.** Cookies-баннер с моделью активного согласия (ДЗ08) и правовые страницы (Политика ПД, ДЗ01).
- **5.7.** Аналитика: Яндекс.Метрика, GA4; цели «отправка заявки», «клик по телефону», «клик по email». При подключении Метрики — обновить Политику ПД (упоминание провайдера).

**Побочные условия сборки** (по итогам теста 20.08.2026): валюта каталога Tilda по умолчанию — доллары, переключить на рубли до заведения товаров; фото по URL с satom.ru платформа не подгружает (403), фото загружаются в CDN Tilda предварительно из локальных файлов `phase-4-content/parsed_v2/photos/`; перед проверкой адресов разделов — назначить любую страницу с блоком каталога главной страницей каталога в настройках.

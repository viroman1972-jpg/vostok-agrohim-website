# Реестр решений о переносе, добавлении и удалении

**Проект:** Редизайн сайта ООО «Восток АгроХим»
**Репозиторий:** `viroman1972-jpg/vostok-agrohim-website`
**Дата создания:** 19 июля 2026
**Статус документа:** живой, обновляется по мере принятия новых решений
**История изменений:** вынесена в `00-management/decisions-changelog.md` (08.08.2026)

---

## Назначение

Единый реестр всех решений по содержимому сайта: что переносится со старого сайта, что переносится с изменениями, что удаляется, что добавляется и на каком основании.

---

## Принципы

Утверждены заказчиком 19 июля 2026.

**1. База — старый сайт.** Всё содержимое сатомовского сайта переносится на новый.

**2. Добавления — только по двум основаниям:**
- **Законодательство** — 38-ФЗ, 152-ФЗ, 149-ФЗ и т.д.
- **Маркетинговое усиление** — заметное повышение доверия или конверсии.

**3. Удаления — по явному решению, задокументированному.**

---

## Формат записи

- **Идентификатор** и краткое название
- **Действие:** перенос / перенос с изменением / удаление / добавление / отказ от добавления
- **Основание:** старый сайт / законодательство / маркетинговое усиление / стратегическое решение клиента
- **Обоснование:** короткая формулировка причины
- **Статус:** принято / требует подтверждения клиента / открыто / отменено
- **Источник:** ссылка на проектный документ, где решение было принято

**Префиксы:** `П` — переносы, `ПИ` — переносы с изменениями, `У` — удаления, `ДЗ` — добавления по законодательству, `ДМ` — добавления по маркетинговому усилению, `НР` — отказы, `ОВ` — открытые вопросы.

Регион работы фиксируется в proof strip Hero — здесь дублирование избыточно и делает H2 длиннее без прибавки смысла.

### ПИ05 — Разделение категорий «Фунгициды» и «Протравители»

### ПИ08 — «Десиканты»: категория восстановлена, реализация — фильтрованное представление по тегу (пересмотр П09 + уточнение 09.08.2026)
- **Действие:** перенос с изменением (заменяет П09, уточняется 09.08.2026)
- **Основание:** техническая упорядоченность таксономии + фактические данные верификации каталога + дискаверабилити

**Редакция 1 (08.08.2026) — первичное решение:**
- **Обоснование:** решение П09 (26.07.2026) сохраняло «Десиканты» отдельной категорией из соображений семантики задачи. По итогам верификации всего каталога СЗР 08.08.2026 выявлено:
  - Единственный десикант в ассортименте — **Суховей, ВР** (дикват дибромид 150 г/л) от АО Фирма «Август»
  - Регистрация двойная: **021-03(04)-9729-0** — категория 03 (гербициды) + 04 (десиканты)
  - Предуборочная десикация — типовой сценарий применения многих глифосатов (Торнадо 540, Силач и др.) и диквата, не эксклюзивный препарата
  - Отдельная категория с одним товаром при том, что «десикация» — универсальное применение, создаёт визуальный дисбаланс в навигации каталога
- **Что было решено 08.08.2026:** «Десиканты» устраняются как отдельная категория; в каталоге на замену вводится **тег/атрибут «Десикант»** для товаров с таким применением. Суховей относится к категории «Гербициды» с тегом «Десикант».

**Редакция 2 (09.08.2026) — уточнение:**
- **Что переоценено:** отсутствие категории «Десиканты» в навигации создавало дыру в дискаверабилити — клиент, приходящий с задачи «нужен десикант», не находил нужного за один клик. Из 4 параллельных входов в каталог сценарий десикации ни одним не покрывался (по вредному объекту — не применимо; по культуре — да, но клиент приходит с задачи, а не с культуры).
- **Компромиссное решение:** категория «Десиканты» **восстанавливается в навигации** (7 категорий в §3 catalog-ia-v1.md v1.3), но её техническая реализация — **фильтрованное представление** над каталогом по условию `tag=desikaciya`. Суховей физически остаётся в «Гербицидах» с тегом «Десикант» — одна карточка, две точки входа. Механика тега сохраняется, семантическое решение проблемы двойной регистрации Суховея сохраняется, а навигационная категория присутствует.
- **Масштабирование:** при пополнении ассортимента препаратом, зарегистрированным на десикацию, в карточке проставляется тег `desikaciya` — автоматически появляется на `/catalog/desikanty/`. Пере-настройка каталога не требуется.
- **Открытая перспектива:** при росте словаря тегов применения (≥4–5 значений: `desikaciya`, `predposevnaya_obrabotka`, `poslevshodovaya` и т.д.) добавляется 5-й параллельный вход «По сценарию применения» — см. §6.6 catalog-ia-v1.md.

- **Что меняется в схеме итого:** «Десиканты» — 7-я категория; URL `/catalog/desikanty/` присутствует; поле «Тег применения» в §4.C схемы; закрытый словарь «Тег применения» в §5; фильтр «Тег применения» в §8 (категорийный для Гербицидов).
- **Затронуто:** структура каталога (7 категорий вместо 6), URL, фильтры листинга, карточка товара, механика фильтрованного представления как категории (новое).
- **Что остаётся:** ДМ10 (Суховей — один из топ-4 препаратов главной), карточка препарата, весь контент по применению.
- **Статус:** принято 08.08.2026 (первичное решение); уточнено 09.08.2026 (компромиссная реализация); действует в текущей форме
- **Источник:** `phase-4-content/verification-snapshot-2026-08-08.md`, сессия верификации каталога; обсуждение 09.08.2026 (восстановление категории)

### ПИ09 — Расширение схемы каталога по итогам сплошного аудита фильтров старого сайта
- **Действие:** перенос с изменением схемы данных
- **Основание:** старый сайт (сплошной обход всех 7 категорий 09.08.2026) + техническая упорядоченность
- **Обоснование:** первичная схема каталога (catalog-ia-v1.md v1.0–v1.2) была составлена по 16-блочной анатомии карточки, но не сверена со сплошным перечнем фильтров сайдбара категорий старого сайта. Обход 09.08.2026 (гербициды, инсектициды, протравители — категории с сайдбаром; фунгициды/адъюванты/десиканты/стимуляторы — без сайдбара, у Satom он не появляется при коротком списке товаров) выявил 8 фильтров, не выведенных в §8, и 2 поля с некорректным типом (строка → должно быть справочником).

**Что меняется в схеме (детально в catalog-ia-v1.md v1.3):**
- **§4.A** «Страна производства» — строка → справочник; стартовый словарь {Россия, Китай, Венгрия}, расширяется по факту.
- **§4.B** добавлено поле «Функциональный подтип» — категорийное; для инсектицидов {инсектицид, инсектоакарицид}, для остальных — TBD.
- **§4.B** «Характер действия» — было «только для гербицидов», стало универсальным (по факту старого сайта — есть у инсектицидов и протравителей).
- **§4.C** «Срок применения» — строка → справочник; стартовый словарь {грунтовой, довсходовый, за 4–5 недель до посева, послевсходовый, в период вегетации}, расширяется.
- **§4.E** явно вынесено поле «Наличие» — источник для бейджа на карточке и фильтра «Только в наличии».
- **§5** словарь «Действующее вещество» расширен атрибутом «Химический класс» — база для нового фильтра.
- **§8** переписан: 15 универсальных фильтров + 3 категорийных, добавлен фильтр «Химический класс ДВ», отдельно закреплено правило скрытия фильтра с единственным значением (наша добавка сверх старого сайта).

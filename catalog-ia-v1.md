## 1. Назначение и границы

Документ описывает **логическую структуру каталога** нового сайта: категории, схему данных карточки препарата, контролируемые словари, четыре параллельных входа в каталог, схему URL и состав фильтров на листинге категории.

**В документ не входят:**
- Вайрфреймы страниц каталога и карточки препарата (следующий шаг)
- Визуальный дизайн (Phase 3)
- Финальный перечень действующих веществ, культур, вредных объектов — извлекается при миграции контента (Phase 4)
- Реализационные ограничения Tilda — уточняются на этапе вёрстки (Phase 5)

**Опирается на:**
- `phase-1-analysis/1.1-site-a-audit/pages-inventory.md` — инвентаризация категорий старого сайта
- `phase-1-analysis/1.1-site-a-audit/product-card-anatomy.md` — 16 блоков карточки препарата
- `00-management/decisions-registry.md` — принятые решения

## 3. Категории каталога

Верхний уровень навигации. **Семь категорий, плоская структура, без вложенности.**

| # | Категория | Slug | На старом сайте | Комментарий |
|---|---|---|---|---|
| 1 | Гербициды | `gerbitsidy` | 44 карточки | + подраздел «Промышленные» (§3.2) |
| 2 | Инсектициды | `insektitsidy` | 14 карточек | без изменений |
| 3 | Фунгициды | `fungitsidy` | ~11 карточек | выделено из старой смешанной категории (ПИ05) |
| 4 | Протравители | `protraviteli` | 15 карточек | выделено из старой смешанной категории (ПИ05) |
| 5 | Стимуляторы роста | `stimulyatory-rosta` | 2 карточки | пересчёт после У05 (Лигногумат исключён) |
| 6 | Адьюванты (ПАВы, прилипатели) | `adyuvanty` | 4 карточки | название нормализовано |
| 7 | Десиканты | `desikanty` | 1 карточка | реализована как фильтрованное представление; см. §3.1 |

**Итого позиций:** ~91 минус исключённые У02–У06 (Ректор КС, Альфацин КЭ, Лазурит Ультра СК, Лигногумат, Тиара КС) — уточнится при финализации каталога.

### 3.1 Десиканты — категория с фильтрованной реализацией

Единственный десикант в ассортименте — **Суховей, ВР** от АО Фирма «Август». Регистрация двойная: **021-03(04)-9729-0** — категория 03 (гербициды) + 04 (десиканты). Предуборочная десикация — сценарий применения, а не химическая категория; типична также для многих глифосатов и диквата.

**Реализация:**

- В каталоге препаратов Суховей физически относится к категории **«Гербициды»**; тег применения = `desikaciya`.
- Страница `/catalog/desikanty/` — навигационная категория и **фильтрованное представление** над каталогом по условию `tag=desikaciya`. Крошки, заголовок, лид, SEO-текст — как у полноценной категории.
- Один препарат — одна карточка данных; две точки входа, без дублирования содержимого.
- В блоке «Каталог» на главной и в футере — «Десиканты» одна из 7 категорий.

**Масштабирование:** при пополнении ассортимента препаратом, зарегистрированным на десикацию, в его карточке проставляется тег `desikaciya` — автоматически появляется на `/catalog/desikanty/`. Пере-настройка каталога не требуется.

### 3.2 Гербициды промышленного применения — подраздел (ДМ31)

На промышленные гербициды (обочины дорог, ж/д, ЛЭП, промзоны) приходится 30–40% продаж. Аудитория — муниципалитеты, дорожные службы, энергетики, промпредприятия — отличается от сельхозпроизводителей запросами и мотивацией.

- **URL:** `/catalog/gerbitsidy/promyshlennye/` — подраздел внутри гербицидов, не категория верхнего уровня
- Свой H1, SEO-текст, отдельная мета
- Тег «Промышленное применение» на карточках соответствующих препаратов
- На посадочной — сценарные входы: обочины дорог / ж-д полотно / ЛЭП / промзоны
- В карточке препарата, применяемого и в сельхозе, и промышленно, — два сценария применения (регламент отдельными вкладками)

## 4. Схема данных карточки препарата

Основана на 16 блоках `product-card-anatomy.md`. Ниже — сгруппированная схема полей.

### 4.1 Источники полей (ПИ10, Принцип 4 реестра)

Юридически значимые поля — регистрационный номер, ДВ, срок регистрации, **срок хранения**, класс опасности, регламент применения — берутся из **госреестра (agroxxi.ru)**. Данные старого сайта и avgust.com используются для сверки; при расхождении приоритет у реестра. Коммерческие поля (цена, фасовка) — со старого сайта или от Прутяна А.В.

### A. Идентификация

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Полное название с концентрацией д.в. | строка | да | старый сайт |
| Slug (для URL) | строка | да | генерируется из названия |
| Категория | справочник (см. §3) | да | старый сайт, нормализовано |
| Производитель | справочник | да | госреестр (= регистрант) |
| Страна производства | справочник | нет | старый сайт (ПИ09) |
| Форма выпуска | справочник (СК, ВДГ, КЭ, ...) | да | старый сайт |

### B. Классификация

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Действующее вещество | список из справочника | да | госреестр |
| Тип препарата | справочник (органический / неорганический) | нет | старый сайт |
| Действие на организм | справочник (кишечное, контактное, системное, фумигативное) | нет | старый сайт |
| Характер действия | справочник (избирательный / сплошной) | нет | старый сайт (ПИ09: универсально) |
| Функциональный подтип | справочник (категорийное поле) | категорийное | старый сайт (ПИ09) |

### C. Область применения

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Культура | множественный справочник | да | госреестр |
| Вредный объект | множественный справочник | да | госреестр |
| Способ применения | справочник (опрыскивание, обработка семян, ...) | да | госреестр |
| Срок применения | справочник | нет | старый сайт (ПИ09) |
| Тег применения | множественный справочник | нет | ПИ08 уточнение; ДМ31 — тег «Промышленное применение» |

### D. Регламент применения

Табличные данные (одна карточка → одна таблица регламентов):
- Культура → вредный объект → норма расхода (л/га или кг/га) → расход рабочей жидкости → срок ожидания → кратность обработки

Хранится как связная таблица, не сериализуется в свободный текст. Источник — госреестр.

Для препаратов двойного применения (сельхоз + промышленное, ДМ31) — два сценария отдельными вкладками.

**Значения флага доставки:**
- `TK_RF` — «Доставка ТК по РФ» (зелёный бейдж)
- `SAMOVYVOZ_ONLY` — «Только самовывоз из Челябинска» (жёлтый бейдж)

**Поле «Наличие» удалено (ПИ11, 17.08.2026).** Восток АгроХим не держит склад — товары привозятся под заявку от АО Фирма «Август». Живой учёт требует еженедельной синхронизации; ошибка = обещание, которое не сможем выполнить. Все товары каталога считаются доступными для заказа; снятый с продажи препарат не помечается, а убирается с сайта. Флаг доставки при этом остаётся — он про способ получения, а не про наличие.

## 6. Четыре параллельных входа в каталог (реализация ДМ02)

Клиенту-агроному нужен доступ к каталогу под несколько сценариев поиска:

- «Покажите гербициды» — вход по типу препарата
- «Что применить на пшенице от септориоза?» — вход по культуре
- «Чем травить колорадского жука?» — вход по вредному объекту
- «Есть у вас препараты на основе глифосата?» — вход по действующему веществу

### 6.1 Вход 1. По типу препарата
- **Что:** 7 категорий (§3); **URL:** `/catalog/{category-slug}/`

### 6.2 Вход 2. По культуре
- **URL:** `/catalog/kultura/{culture-slug}/`; SEO-ценность высокая — запросы вида «гербицид для пшеницы», «инсектицид на картофель»

### 6.3 Вход 3. По вредному объекту
- **URL двух уровней:** hub `/catalog/vrednyy-obekt/{subtype}/` + конкретный объект `/catalog/vrednyy-obekt/{pest-slug}/`
- Hub-страницы по подтипу добавлены ДМ26; тайлы блока 4 главной ведут на hub-страницы подтипов

### 6.4 Вход 4. По действующему веществу
- **URL:** `/catalog/dv/{substance-slug}/`

### 6.5 Служебная страница «Все препараты»
- **URL:** `/catalog/all/`

### 6.6 Возможный 5-й вход. По сценарию применения
При росте словаря тегов до ~4–5 значений имеет смысл 5-й параллельный вход «По сценарию применения». Пока теги обслуживают две точки: категорию «Десиканты» (§3.1) и подраздел «Промышленные» (§3.2).

### 6.7 Обзорные страницы под торговые серии (реализация ПИ06)
Обзорная страница создаётся только для серий (≥2 препаратов под одним торговым именем). URL: `/catalog/seriya/{brand-slug}/`.

```
/catalog/desikanty/                          — категория с фильтрованной реализацией (tag=desikaciya, ПИ08)
```

## 10. Cross-sell и связанные препараты (ДМ29)

На карточке препарата — блок «Смотрите также», ровно 4 позиции. Алгоритм слотов утверждён Прутяном А.В. 13.08.2026:

| Слот | Правило |
|---|---|
| 1 | **Фикс во всех карточках** — Альбит, ТПС (биостимулятор, добавляется к любой обработке) |
| 2 | **Баковый партнёр** — препарат, с которым данный СЗР реально смешивают для расширения спектра и/или удешевления обработки. Приоритет над аналогом по ДВ |
| 3 | **Комплементарный по функции** — препарат другого типа на тех же культурах (против других объектов) |
| 4 | **Другой класс на тех же культурах** — фунгицид, инсектицид или протравитель |

Исключённые из ассортимента препараты (У02–У06) в кросс-селл не попадают.

**Замена прежней логики:** до 13.08.2026 действовал приоритетный список «та же категория + культура → тот же объект → то же ДВ другой формы → тот же химический класс → та же серия». Он оказался слишком механическим: аналог по ДВ рядом с основным препаратом бесполезен покупателю. Новый алгоритм строится от практики применения.

Данные для 91 SKU собираются матрицей — отдельный этап Phase 4.

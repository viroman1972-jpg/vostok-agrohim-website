## 1. Назначение и границы

Документ описывает **логическую структуру каталога** нового сайта: категории, схему данных карточки препарата, контролируемые словари, четыре параллельных входа в каталог, схему URL и состав фильтров на листинге категории.

**В документ не входят:**
- Вайрфреймы страниц каталога и карточки препарата (следующий шаг)
- Визуальный дизайн (Phase 3)
- Финальный перечень действующих веществ, культур, вредных объектов — извлекается при миграции контента (Phase 4)
- Реализационные ограничения Tilda — уточняются на этапе вёрстки (Phase 5)

**Опирается на:**
- `phase-1-analysis/1.1-site-a-audit/pages-inventory.md` — инвентаризация категорий старого сайта
- `phase-1-analysis/1.1-site-a-audit/product-card-anatomy.md` — 16 блоков карточки препарата
- `00-management/decisions-registry.md` — принятые решения

## 3. Категории каталога

Верхний уровень навигации. **Семь категорий, плоская структура, без вложенности.**

| # | Категория | Slug | На старом сайте | Комментарий |
|---|---|---|---|---|
| 1 | Гербициды | `gerbitsidy` | 44 карточки | без изменений |
| 2 | Инсектициды | `insektitsidy` | 14 карточек | без изменений |
| 3 | Фунгициды | `fungitsidy` | ~11 карточек | выделено из старой смешанной категории (ПИ05) |
| 4 | Протравители | `protraviteli` | 15 карточек | выделено из старой смешанной категории (ПИ05) |
| 5 | Стимуляторы роста | `stimulyatory-rosta` | 2 карточки | без изменений |
| 6 | Адьюванты (ПАВы, прилипатели) | `adyuvanty` | 4 карточки | название нормализовано |
| 7 | Десиканты | `desikanty` | 1 карточка | реализована как фильтрованное представление; см. §3.1 |

**Итого позиций:** ~91 (уточнится при миграции).

### 3.1 Десиканты — категория с фильтрованной реализацией

По состоянию на 09.08.2026 в ассортименте единственный десикант — **Суховей, ВР** от АО Фирма «Август». Регистрация двойная: **021-03(04)-9729-0** — категория 03 (гербициды) + 04 (десиканты). Предуборочная десикация — сценарий применения, а не химическая категория; типична также для многих глифосатов и диквата.

**Реализация:**

- В каталоге препаратов Суховей физически относится к категории **«Гербициды»** — как основная агрономическая функция; тег применения = `desikaciya`.
- Страница `/catalog/desikanty/` — навигационная категория и **фильтрованное представление** над каталогом по условию `tag=desikaciya`. Крошки, заголовок, лид, SEO-текст — как у полноценной категории (см. §8).
- Один препарат — одна карточка данных; две точки входа: `/catalog/gerbitsidy/` (среди 44 карточек) и `/catalog/desikanty/` (пока единственная). Без дублирования содержимого.
- В блоке «Каталог» на главной и в футере — «Десиканты» одна из 7 категорий.
- В навигации фильтров листинга гербицидов — фильтр «Тег применения» с значением «Десикант».

**Масштабирование:** при пополнении ассортимента препаратом, зарегистрированным на десикацию (глифосат, дикват, аналог), в его карточке проставляется тег `desikaciya` — автоматически появляется на `/catalog/desikanty/`. Пере-настройка каталога не требуется.

## 6. Четыре параллельных входа в каталог (реализация ДМ02)

Клиенту-агроному нужен доступ к каталогу под несколько сценариев поиска:

- «Покажите гербициды» — вход по типу препарата
- «Что применить на пшенице от септориоза?» — вход по культуре
- «Чем травить колорадского жука?» — вход по вредному объекту
- «Есть у вас препараты на основе глифосата?» — вход по действующему веществу

### 6.1 Вход 1. По типу препарата
- **Что:** 7 категорий (§3); **URL:** `/catalog/{category-slug}/`

### 6.2 Вход 2. По культуре
- **URL:** `/catalog/kultura/{culture-slug}/`; SEO-ценность: высокая — запросы вида «гербицид для пшеницы», «инсектицид на картофель»

### 6.3 Вход 3. По вредному объекту
- **URL двух уровней:** hub `/catalog/vrednyy-obekt/{subtype}/` + конкретный объект `/catalog/vrednyy-obekt/{pest-slug}/`
- Hub-страницы по подтипу добавлены ДМ26 (09.08.2026); тайлы блока 4 главной ведут на hub-страницы подтипов.

### 6.4 Вход 4. По действующему веществу
- **URL:** `/catalog/dv/{substance-slug}/`

### 6.5 Служебная страница «Все препараты»
- **URL:** `/catalog/all/`

### 6.6 Возможный 5-й вход. По сценарию применения
При росте словаря тегов до ~4–5 значений имеет смысл 5-й параллельный вход «По сценарию применения». Пока — только навигационная категория «Десиканты» (§3.1).

### 6.7 Обзорные страницы под торговые серии (реализация ПИ06)
Обзорная страница создаётся только для серий (≥2 препаратов под одним торговым именем). URL: `/catalog/seriya/{brand-slug}/`.

## 7. Схема URL

```
/catalog/                                    — корень каталога
/catalog/all/                                — единый листинг всех
/catalog/{category}/                         — категория
/catalog/{category}/{product-slug}/          — карточка препарата
/catalog/kultura/{culture-slug}/             — вход по культуре
/catalog/vrednyy-obekt/{subtype}/            — hub-страница по подтипу (sornyaki / vrediteli / bolezni, ДМ26)
/catalog/vrednyy-obekt/{pest-slug}/          — страница конкретного вредного объекта
/catalog/dv/{substance-slug}/                — вход по действующему веществу
/catalog/seriya/{brand-slug}/                — обзорная страница серии (только для серий из ≥2 препаратов, ПИ06)
/catalog/desikanty/                          — категория с фильтрованной реализацией (tag=desikaciya, ПИ08 уточнение)
```

## 10. Cross-sell и связанные препараты

На карточке препарата — блок «Смотрите также». Логика формирования (в порядке приоритета): та же категория + та же культура → та же категория + тот же вредный объект → то же ДВ другой формы → тот же химический класс ДВ → та же серия → часто заказываемые вместе. Показывать не более 4 карточек.

## 1. Назначение и границы

Документ описывает **логическую структуру каталога** нового сайта: категории, схему данных карточки препарата, контролируемые словари, четыре параллельных входа в каталог, схему URL и состав фильтров на листинге категории.

**В документ не входят:**
- Вайрфреймы страниц каталога и карточки препарата (следующий шаг)
- Визуальный дизайн (Phase 3)
- Финальный перечень действующих веществ, культур, вредных объектов — извлекается при миграции контента (Phase 4)
- Реализационные ограничения Tilda — уточняются на этапе вёрстки (Phase 5)

**Опирается на:**
- `phase-1-analysis/1.1-site-a-audit/pages-inventory.md` — инвентаризация категорий старого сайта
- `phase-1-analysis/1.1-site-a-audit/product-card-anatomy.md` — 16 блоков карточки препарата
- `00-management/decisions-registry.md` — принятые решения

## 3. Категории каталога

Верхний уровень навигации. **Семь категорий, плоская структура, без вложенности.**

| # | Категория | Slug | На старом сайте | Комментарий |
|---|---|---|---|---|
| 1 | Гербициды | `gerbitsidy` | 44 карточки | без изменений |
| 2 | Инсектициды | `insektitsidy` | 14 карточек | без изменений |
| 3 | Фунгициды | `fungitsidy` | ~11 карточек | выделено из старой смешанной категории (ПИ05) |
| 4 | Протравители | `protraviteli` | 15 карточек | выделено из старой смешанной категории (ПИ05) |
| 5 | Стимуляторы роста | `stimulyatory-rosta` | 2 карточки | без изменений |
| 6 | Адьюванты (ПАВы, прилипатели) | `adyuvanty` | 4 карточки | название нормализовано |
| 7 | Десиканты | `desikanty` | 1 карточка | реализована как фильтрованное представление; см. §3.1 |

**Итого позиций:** ~91 (уточнится при миграции).

### 3.1 Десиканты — категория с фильтрованной реализацией

По состоянию на 09.08.2026 в ассортименте единственный десикант — **Суховей, ВР** от АО Фирма «Август». Регистрация двойная: **021-03(04)-9729-0** — категория 03 (гербициды) + 04 (десиканты). Предуборочная десикация — сценарий применения, а не химическая категория; типична также для многих глифосатов и диквата.

**Реализация:**

- В каталоге препаратов Суховей физически относится к категории **«Гербициды»** — как основная агрономическая функция; тег применения = `desikaciya`.
- Страница `/catalog/desikanty/` — навигационная категория и **фильтрованное представление** над каталогом по условию `tag=desikaciya`. Крошки, заголовок, лид, SEO-текст — как у полноценной категории (см. §8).
- Один препарат — одна карточка данных; две точки входа: `/catalog/gerbitsidy/` (среди 44 карточек) и `/catalog/desikanty/` (пока единственная). Без дублирования содержимого.
- В блоке «Каталог» на главной и в футере — «Десиканты» одна из 7 категорий.
- В навигации фильтров листинга гербицидов — фильтр «Тег применения» с значением «Десикант».

**Масштабирование:** при пополнении ассортимента препаратом, зарегистрированным на десикацию (глифосат, дикват, аналог), в его карточке проставляется тег `desikaciya` — автоматически появляется на `/catalog/desikanty/`. Пере-настройка каталога не требуется.

**Замечания по категориям:**

- Категории «Фунгициды и протравители» и «Протравители» на старом сайте были параллельными и пересекались (техническая ошибка). На новом сайте разделены на две плоские категории (ПИ05): протравитель — форма применения (обработка семян), фунгицид — тип действия (защита вегетирующих растений). Клиент решает разные задачи.
- Для «Адьюванты (ПАВы, прилипатели)» на странице категории — короткий пояснительный лид: адъювант = вспомогательное вещество для рабочей смеси. Помогает клиенту, ищущему по разному термину, попасть на правильную страницу.
- Порядок в меню и на главной странице каталога — по объёму ассортимента (гербициды первыми, стимуляторы, адьюванты и десиканты в хвосте).

## 4. Схема данных карточки препарата

Основана на 16 блоках `product-card-anatomy.md`. Ниже — сгруппированная схема полей.

### A. Идентификация

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Полное название с концентрацией д.в. | строка | да | старый сайт |
| Slug (для URL) | строка | да | генерируется из названия |
| Категория | справочник (см. §3) | да | старый сайт, нормализовано |
| Производитель | справочник | да | старый сайт |
| Страна производства | справочник | нет | старый сайт (ПИ09: было — строка, стало — справочник) |
| Форма выпуска | справочник (СК, ВДГ, КЭ, ...) | да | старый сайт |

### B. Классификация

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Действующее вещество | список из справочника | да | старый сайт |
| Тип препарата | справочник (органический / неорганический) | нет | старый сайт |
| Действие на организм | справочник (кишечное, контактное, системное, фумигативное) | нет | старый сайт |
| Характер действия | справочник (избирательный / сплошной) | нет | старый сайт (ПИ09: было «только для гербицидов», универсально) |
| Функциональный подтип | справочник (категорийное поле) | категорийное | старый сайт (ПИ09) |

**Замечание по «Функциональному подтипу»:**
Категорийное поле, зависит от категории. На 09.08.2026 закрепляется только для инсектицидов: **инсектицид** / **инсектоакарицид**. Для остальных категорий поле присутствует в схеме, но словарь пуст — заполняется по мере обнаружения на этапе миграции контента.

### C. Область применения

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Культура | множественный справочник | да | старый сайт |
| Вредный объект | множественный справочник | да | старый сайт |
| Способ применения | справочник (опрыскивание, обработка семян, ...) | да | старый сайт |
| Срок применения | справочник | нет | старый сайт (ПИ09: было — строка, стало — справочник) |
| Тег применения | множественный справочник | нет | новое (ПИ08 уточнение 09.08.2026) |

**Замечание по «Тегу применения»:**
Множественный справочник, значения — специальные сценарии применения препарата, не покрываемые основной категорией. Стартовый словарь: `desikaciya`. При пополнении ассортимента справочник расширяется (например: `predposevnaya_obrabotka`, `poslevshodovaya`, `predubrochnaya`). Механизм — база для навигационной категории «Десиканты» (§3.1) и — в перспективе — для 5-го параллельного входа «По сценарию применения» (см. §6.6).

### D. Регламент применения

Табличные данные (одна карточка → одна таблица регламентов):
- Культура → вредный объект → норма расхода (л/га или кг/га) → расход рабочей жидкости → срок ожидания → кратность обработки

Хранится как связная таблица, не сериализуется в свободный текст.

### E. Безопасность

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Класс опасности для человека (1–4) | число | да | старый сайт / ГОСТ 12.1.007 |
| Флаг доставки | boolean | да | новое, блок 11а карточки |
| Наличие | справочник (в наличии / нет в наличии / под заказ) | да | старый сайт (ПИ09: явно вынесено в схему) |
| Ограничения по применению | текст | нет | старый сайт |
| Первая помощь при отравлении | структурированный текст | да | старый сайт |
| Транспортировка и утилизация | текст | нет | старый сайт |
| Охрана окружающей среды | текст | нет | старый сайт |

**Значения флага доставки:**
- `TK_RF` — «Доставка ТК по РФ» (зелёный бейдж)
- `SAMOVYVOZ_ONLY` — «Только самовывоз из Челябинска» (жёлтый бейдж)

**Замечание по полю «Наличие»:**
На старом сайте бейдж «В наличии» / «Нет в наличии» отображается на каждой карточке. Выведено в схему явно, чтобы бейдж на листинге и фильтр «Только в наличии» имели строгий источник данных. Отдельно от поля «Статус публикации» (§4.H) — тот описывает жизненный цикл записи в CMS, а не коммерческий статус остатка.

### F. Логистика и заявка

| Поле | Тип | Обязательное | Источник |
|---|---|---|---|
| Упаковка (тип тары) | справочник (канистра, флакон, пластиковая тара, ...) | нет | старый сайт |
| Размеры упаковки | список чисел с единицами | нет | старый сайт |
| Цена (₽/л или ₽/кг) | число | да | старый сайт (П10) |
| Условия хранения | текст | нет | старый сайт |

**Замечание по цене:** цена на карточке — информационная (базовая розничная), как на старом сайте. Модель работы — витрина с заявкой (У01), без онлайн-эквайринга (НР03), без публичной шкалы скидок (НР02). Точная цена сделки для юрлиц и опта уточняется в заявке.

Полный перечень значений открытых словарей извлекается при миграции контента (Phase 4). На этапе IA важно закрепить сам факт словаря и его роль — см. ОВ10.

## 6. Четыре параллельных входа в каталог (реализация ДМ02)

Клиенту-агроному нужен доступ к каталогу под несколько сценариев поиска:

- «Покажите гербициды» — вход по типу препарата
- «Что применить на пшенице от септориоза?» — вход по культуре
- «Чем травить колорадского жука?» — вход по вредному объекту
- «Есть у вас препараты на основе глифосата?» — вход по действующему веществу

### 6.1 Вход 1. По типу препарата
- **Что:** 7 категорий (§3)
- **Точка входа:** главное меню, блок 4 главной страницы, верхняя часть страницы `/catalog/`
- **URL:** `/catalog/{category-slug}/`

### 6.2 Вход 2. По культуре
- **Что:** посадочные страницы под каждую значимую культуру
- **Точка входа:** на странице `/catalog/` отдельный блок «По культурам», в подвале — раздел «Каталог по культурам»
- **URL:** `/catalog/kultura/{culture-slug}/`
- **Что на странице:** заголовок «Препараты для {культура}», короткий поясняющий лид, список карточек препаратов, применимых к этой культуре, с возможностью дальнейшей фильтрации
- **SEO-ценность:** высокая — запросы вида «гербицид для пшеницы», «инсектицид на картофель»

### 6.3 Вход 3. По вредному объекту
- **Что:** посадочные страницы под каждый значимый вредный объект (вредитель / сорняк / болезнь) + hub-страницы верхнего уровня по подтипу
- **Точка входа:** на странице `/catalog/` отдельный блок «По вредителям, сорнякам и болезням»; тайлы блока 4 главной «Задачи защиты» (сорняки/вредители/болезни) ведут на hub-страницы подтипов (ДМ26)
- **URL двух уровней:**
  - **Hub-страницы по подтипу** (верхний уровень): `/catalog/vrednyy-obekt/sornyaki/`, `/catalog/vrednyy-obekt/vrediteli/`, `/catalog/vrednyy-obekt/bolezni/` — витрина всех препаратов против сорняков / вредителей / болезней с фильтрами и переходами на конкретные объекты
  - **Страницы конкретных объектов** (второй уровень): `/catalog/vrednyy-obekt/{pest-slug}/` — например, `/catalog/vrednyy-obekt/koloradskiy-zhuk/`, `/catalog/vrednyy-obekt/septorioz/`
- **Что на hub-странице:** заголовок «Препараты против {подтип}», короткий поясняющий лид, товарный листинг с фильтрами (по культуре, действующему веществу, форме выпуска и т.д.), плюс блок «По конкретному объекту» со ссылками на страницы второго уровня (топ-10 самых частых объектов подтипа)
- **Что на странице конкретного объекта:** заголовок «Препараты против {объект}», короткое описание проблемы, карточки препаратов
- **SEO-ценность:** высокая для обоих уровней — hub'ы захватывают запросы «средство от сорняков», «препараты от болезней»; страницы конкретных объектов — «средство от колорадского жука», «препарат от септориоза пшеницы»

### 6.4 Вход 4. По действующему веществу
- **Что:** посадочные страницы под каждое значимое действующее вещество
- **Точка входа:** на странице `/catalog/` отдельный блок «По действующим веществам»
- **URL:** `/catalog/dv/{substance-slug}/`
- **Что на странице:** заголовок «Препараты с действующим веществом {д. в.}», короткое описание вещества, карточки препаратов
- **SEO-ценность:** средняя — специалистские запросы: «глифосат», «имидаклоприд»

### 6.5 Служебная страница «Все препараты»
- **URL:** `/catalog/all/`
- Полный листинг всех препаратов с фильтрами и поиском. Инструмент для тех, кто предпочитает один листинг перед четырьмя входами.

### 6.6 Возможный 5-й вход. По сценарию применения (открытый вопрос)

По итогам ПИ08 (уточнение 09.08.2026) в схеме появился «Тег применения» — атрибут, отражающий сценарий (`desikaciya`, потенциально `predposevnaya_obrabotka`, `poslevshodovaya` и т.п.). При росте словаря тегов до ~4–5 значений имеет смысл 5-й параллельный вход: «По сценарию применения». Пока в тегах одно значение — реализовано только как навигационная категория «Десиканты» (§3.1). Полноценный 5-й вход откладывается до момента, когда словарь тегов оправдает отдельный блок навигации.

### 6.7 Обзорные страницы под торговые серии (реализация ПИ06)

На старом сайте у карточек препаратов были теги, в том числе с торговыми именами (Торнадо 540, Торнадо 500, Магнум гербицид, Балерина, Лазурит, Миура, Колосаль, Брейк). На новом сайте:

- **Обзорная страница создаётся только для серий** — когда под одним торговым именем в ассортименте несколько препаратов (например, «Торнадо» → Торнадо 540 + Торнадо 500). Такая страница даёт зонтичный SEO-заход по «торнадо гербицид», ссылки на конкретные карточки и краткое сравнение.
- **Для одиночных препаратов** (Магнум, Балерина Форте, Ордан) отдельная посадочная не нужна — SEO-запросы вида «магнум гербицид купить», «балерина форте цена» ранжируются самой карточкой препарата с оптимизированными title/H1/description.
- **Действующие вещества** (глифосат, прометрин, циперметрин, клопиралид, ...) — сохраняются как «Вход 4. По действующему веществу» (§6.4).
- **Общие фильтровые теги** («Гербициды сплошного действия», «Гербициды Август») — реализуются как фильтры внутри категории (§8), не как отдельные страницы.

**URL обзорных страниц серий:** `/catalog/seriya/{brand-slug}/` (пример: `/catalog/seriya/tornado/`). Финальный список серий определяется на этапе миграции контента (Phase 4) — исходя из того, у каких торговых имён в ассортименте больше одного препарата.

## 7. Схема URL

Единая согласованная логическая схема:

```
/catalog/                                    — корень каталога
/catalog/all/                                — единый листинг всех
/catalog/{category}/                         — категория
/catalog/{category}/{product-slug}/          — карточка препарата
/catalog/kultura/{culture-slug}/             — вход по культуре
/catalog/vrednyy-obekt/{subtype}/            — hub-страница по подтипу (sornyaki / vrediteli / bolezni, ДМ26)
/catalog/vrednyy-obekt/{pest-slug}/          — страница конкретного вредного объекта
/catalog/dv/{substance-slug}/                — вход по действующему веществу
/catalog/seriya/{brand-slug}/                — обзорная страница серии (только для серий из ≥2 препаратов, ПИ06)
/catalog/desikanty/                          — категория с фильтрованной реализацией (tag=desikaciya, ПИ08 уточнение)
```

**Правила слагов:**

- Транслит русских названий по стандарту (нижний регистр, дефисы вместо пробелов)
- Категории — уже зафиксированы в §3
- Slug препарата — из его официального названия, без концентрации: `tornado-540`, `boreiy-neo`, `magnum`, `ordan`, `balerina-forte`, `gaur`
- Slug культуры — простое существительное в именительном падеже: `pshenitsa`, `yachmen`, `kukuruza`
- Slug вредного объекта — простое имя без служебных слов: `koloradskiy-zhuk`, `dvudolnye-sornyaki`, `septorioz`
- Slug действующего вещества — научное название: `glifosat`, `imidakloprid`, `metsulfuron-metil`
- Slug серии — торговое имя без указания концентрации: `tornado`, `layzurit`, `mira`

**Замечание по Tilda:**

Схема выше — логическая. Тильда накладывает ограничения на структуру URL. При реализации Phase 5 схема адаптируется к возможностям платформы; логическая структура и стратегия SEO остаются неизменными. Возможные пути реализации — использование T-Store каталога с вложенными разделами, либо генерация посадочных как отдельных Zero-block страниц с ЧПУ-адресами.

| Фильтр | Категория | Значения |
|---|---|---|

| Подтип вредного объекта | Инсектициды / Гербициды / Фунгициды | вредитель / сорняк / болезнь |

### Компоновка (реализует ДМ23)

Развёрнуты по умолчанию (4 фильтра сайдбара): **Действующее вещество, Культура, Вредный объект, Форма выпуска**. Остальные — под кнопкой «Ещё фильтры» / drawer на мобильном.

### Поведение фильтров

- Множественный выбор внутри фильтра — логика ИЛИ; между фильтрами — И.
- Каждое значение фильтра показывает количество препаратов, попадающих под него в текущей выборке.
- Фильтр отображается только если у текущей выборки есть больше одного значения (например, если в категории все препараты одного производителя, фильтр «Производитель» скрывается автоматически). Это **отличие от старого сайта** — там фильтр с единственным значением всё равно показывается; наше поведение — улучшение UX.
- Комбинация активных фильтров имеет собственный URL (`?substance=glifosat&culture=pshenitsa`) — для копирования ссылки и SEO.
- Активные фильтры отображаются чипсами со сбросом каждого и кнопкой «Сбросить все».

### Быстрый доступ (chip-строки над фильтрами)

Над сеткой продуктов — две строки быстрого доступа:

1. **Серии** — торговые серии, представленные в текущей категории ≥2 препаратами (ПИ06). Динамически по факту.
2. **Действующее вещество** — топ-N самых частых ДВ в текущей выборке; логика уточнения топ-N — см. ОВ18.

Плюс отдельный быстрый чип «Только Август» — соответствует тегу `Гербициды Август` старого сайта (в категориях, где ассортимент есть).

### Сортировка

- По популярности (по умолчанию) — метрика уточняется; стартовая: по количеству заказов за 12 мес. или редакционно, если данных нет (см. ОВ13)
- По названию (А→Я)
- По классу опасности (возрастание)
- По цене (возрастание / убывание)

### Пагинация

- 12 карточек на странице по умолчанию
- Опция «показать всё» — для сегмента пользователей, которым удобнее один длинный список

## 9. Поиск

Полнотекстовый поиск по каталогу — отдельная фича, поверх схемы данных.

**Индексируются:**
- Название препарата (включая устаревшие и альтернативные написания)
- Действующее вещество (все значения)
- Синонимы, торговые имена, транскрипции
- Культура (все значения)
- Вредный объект (все значения)
- Производитель

**Не индексируются:**
- Свободный маркетинговый текст (слишком «шумит», ухудшает релевантность)
- Служебные поля

**Результаты поиска** — единый листинг с теми же фильтрами и сортировкой, что на странице категории, но без ограничения по категории.

Конкретная реализация — при вёрстке в Tilda. Если встроенный поиск Tilda не покрывает требования, рассматривается интеграция стороннего решения (Search Anise или аналог).

## 10. Cross-sell и связанные препараты

На карточке препарата — блок «Смотрите также». Логика формирования (в порядке приоритета):

1. Препараты той же категории, с той же культурой в списке применения
2. Препараты той же категории, с тем же вредным объектом
3. Препараты того же действующего вещества, но другой формы выпуска
4. Препараты того же химического класса ДВ (ПИ09) — расширение при бедной первичной выборке
5. Препараты той же серии (для серий из ≥2 препаратов, ПИ06)
6. Препараты, часто заказываемые вместе (если статистика доступна)

Не показывать препараты, снятые с продажи. Показывать не более 4 карточек.

## 11. Новые решения этого документа

Оформляются как записи в `00-management/decisions-registry.md`:

### ПИ05 — Разделение «Фунгициды» и «Протравители» на две плоские категории
- **Действие:** перенос с изменением
- **Основание:** техническая упорядоченность таксономии
- **Обоснование:** на старом сайте параллельно существовали категория «Протравители» (15 товаров) и категория «Фунгициды и протравители» (11 товаров) с пересекающимся содержимым. Протравитель — форма применения (обработка семян), фунгицид — тип действия (защита вегетирующих растений). На новом сайте — две отдельные плоские категории; клиент ищет решение под свою задачу.
- **Затронуто:** структура каталога, URL, миграция контента, фильтры
- **Статус:** принято 26.07.2026

### П09 / ПИ08 — «Десиканты»: категория восстановлена, реализация — фильтрованное представление
- **История:** П09 (26.07.2026) сохранял «Десиканты» отдельной категорией. ПИ08 (08.08.2026) — устранял категорию, заменял её тегом внутри «Гербицидов». Настоящая редакция (09.08.2026) — уточнение ПИ08: категория **восстанавливается в навигации**, но реализуется технически как фильтрованное представление по тегу.
- **Что теперь:** «Десиканты» — 7-я категория в §3, URL `/catalog/desikanty/`, но её содержимое собирается фильтром `tag=desikaciya` над каталогом. Суховей физически относится к «Гербицидам» с тегом «Десикант» — одна карточка, две точки входа. См. §3.1.
- **Обоснование правки 09.08.2026:** отсутствие категории в навигации создаёт дыру в дискаверабилити — клиент, приходящий с задачи «нужен десикант», не находит нужного за один клик. Компромиссная механика (категория как фильтр) сохраняет техническую чистоту решения проблемы двойной регистрации Суховея и даёт масштабируемый паттерн для роста ассортимента.
- **Затронуто:** §3 (7 категорий), §3.1 (описание механики), §4.C (поле «Тег применения»), §5 (закрытый словарь «Тег применения»), §8 (категорийный фильтр «Тег применения»), URL (возвращается `/catalog/desikanty/`).
- **Статус:** принято 09.08.2026

### П10 — Цены на карточке препарата (закрытие ОВ11)
- **Действие:** перенос
- **Основание:** старый сайт
- **Обоснование:** на старом сайте цена препарата (₽/л или ₽/кг) показывается на каждой карточке рядом с блоком заявки. На новом сайте цена показывается в том же виде: базовая розничная, информационная. Модель работы — витрина с заявкой (У01), без онлайн-эквайринга (НР03), без публичной шкалы скидок (НР02). Точная цена сделки для юрлиц и опта уточняется в заявке.
- **Затронуто:** §4F схемы данных карточки, сортировка на листинге (§8), состав полей карточки
- **Статус:** принято 26.07.2026 (заказчиком)

### ПИ06 — SEO-посадочные под торговые имена только для серий (закрытие ОВ12)
- **Действие:** перенос с изменением
- **Основание:** старый сайт + техническая упорядоченность SEO
- **Обоснование:** на старом сайте у карточек препаратов есть теги (~15+), кликающиеся на страницы-фильтры. Теги смешанные: торговые имена (Торнадо 540, Магнум, Лазурит, Колосаль, Брейк), действующие вещества (глифосат, прометрин, циперметрин), общие фильтры (Гербициды сплошного действия). На новом сайте:
  - **Действующие вещества** — сохраняются, реализуются как «Вход 4. По действующему веществу» из ДМ02 (§6.4)
  - **Общие фильтровые теги** — реализуются как фильтры внутри категории (§8, «Характер действия»)
  - **Торговые имена** — обзорная страница создаётся только для серий с несколькими препаратами (например, «Торнадо» под Торнадо 540 + Торнадо 500). Для одиночных препаратов (Магнум, Балерина Форте, Ордан) отдельная посадочная не нужна: карточка препарата сама покрывает точные запросы вида «магнум гербицид купить».
- **Затронуто:** §6.7, §7, §10 catalog-ia-v1.md, миграция контента (Phase 4)
- **Статус:** принято 26.07.2026 (заказчиком)

### ПИ09 — Расширение схемы каталога по итогам сплошного аудита фильтров старого сайта
- **Действие:** перенос с изменением схемы данных
- **Основание:** старый сайт (сплошной обход всех 7 категорий 09.08.2026) + техническая упорядоченность
- **Обоснование:** первичная схема (v1.0–v1.2) была составлена по 16-блочной анатомии карточки, но не сверена со сплошным перечнем фильтров сайдбара категорий старого сайта. Обход 09.08.2026 (гербициды, инсектициды, протравители — категории с сайдбаром; фунгициды/адъюванты/десиканты/стимуляторы — без сайдбара из-за короткого списка препаратов) выявил 8 фильтров, не выведенных в §8, и 2 поля с некорректным типом (строка → должно быть справочником).
- **Что меняется в схеме:**
  - **§4.A** «Страна производства» — строка → справочник; стартовый словарь {Россия, Китай, Венгрия}, расширяется по факту.
  - **§4.B** добавлено поле «Функциональный подтип» — категорийное; для инсектицидов {инсектицид, инсектоакарицид}, для остальных — TBD.
  - **§4.B** «Характер действия» — было «только для гербицидов», стало универсальным (по факту старого сайта — есть у инсектицидов и протравителей).
  - **§4.C** «Срок применения» — строка → справочник; стартовый словарь {грунтовой, довсходовый, за 4–5 недель до посева, послевсходовый, в период вегетации}, расширяется.
  - **§4.E** явно вынесено поле «Наличие» — источник для бейджа на карточке и фильтра «Только в наличии».

### ОВ18 — Механика топ-N ДВ для chip-строки быстрого доступа (§8)
- **Что:** над сеткой продуктов показывается строка чипов «Действующее вещество» — топ-N популярных ДВ в текущей выборке. Способ выбора топ-N: (а) по количеству препаратов с этим ДВ; (б) редакционно закреплённые ДВ для каждой категории. Значение N — 3, 4 или 5.
- **Когда решается:** до Phase 5.

### ОВ19 — Способ заведения поля «Наличие»
- **Что:** новое явное поле §4.E. Варианты источника: (а) ручное редактирование в CMS Tilda; (б) интеграция с 1С заказчика (если есть); (в) периодический импорт из внешнего файла. Влияет на регламент сопровождения (Phase 9).
- **Когда решается:** до Phase 5.

### ОВ21 — Заполнение атрибута «Химический класс» для словаря ДВ
- **Что:** атрибут словаря «Действующее вещество» (§5, ПИ09), значения: имидазолы, триазолы, никотеноиды, фенилпирролы, пиретроиды, глифосаты, сульфонилмочевины и др. Заполняется для каждого ДВ каталога.
- **Когда решается:** Phase 4, при миграции контента и заведении полного словаря ДВ.

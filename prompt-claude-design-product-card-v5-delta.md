## Изменение 3: Cross-sell — заменить плейсхолдеры реальными данными

Заменить:
```js
crossSell: [1, 2, 3, 4].map(n => ({ name: "Препарат " + n, dv: "Действующее вещество подставится при сборке каталога" })),
```

На:
```js
crossSell: [
  {
    name:  "Альбит, ТПС",
    dv:    "Биостимулятор + фунгицид. Усиливает эффект гербицидной обработки, стимулирует восстановление культуры.",
    cat:   "Биопрепарат",
    href:  "/catalog/biopreparaty/albit-tps/",
  },

    name:  "Гербитокс, ВРК",

    cat:   "Гербицид",
    href:  "/catalog/gerbitsidy/gerbitoks-vrk/",
  },
  {
    name:  "Ластик Топ, МКЭ",
    dv:    "Феноксапроп-П-этил + клодинафоп-пропаргил + клоквинтосет. Против злаковых сорняков на пшенице — комплексная защита культуры.",
    cat:   "Гербицид",
    href:  "/catalog/gerbitsidy/lastik-top/",
  },
  {
    name:  "Колосаль Про, КМЭ",
    dv:    "Протиоконазол + тебуконазол. Фунгицид широкого спектра на зерновых — мучнистая роса, септориоз, бурая ржавчина.",

    href:  "/catalog/fungitsidy/kolosal-pro/",
```

В шаблоне cross-sell блока:
- Бейдж категории: заменить захардкоженный `«Гербицид»` на `{{ p.cat }}`
- Ссылка карточки: заменить `href="#"` на `href="{{ p.href }}"`
- Убрать строку-плейсхолдер под блоком: `<p style="...">Плейсхолдер: подбор по правилу...</p>`

## Логика cross-sell (зафиксировано, не в промпт Claude Design)

Источник — решение Прутяна А.В. 12.08.2026:
- **Альбит** — фиксированный слот 1 во всех карточках каталога
- **Гербитокс** — аналог по ДВ (феноксикарбоксилат/ауксин, тот же класс что 2,4-Д в Балерине)
- **Ластик Топ** — комплементарный по функции (злаковые сорняки, тот же зерновой ценоз — пример прямо из письма Прутяна)
- **Колосаль Про** — фунгицид на тех же культурах (комплексная защита посева)

Лигногумат убран по решению Прутяна (неизвестно наличие в следующем сезоне).

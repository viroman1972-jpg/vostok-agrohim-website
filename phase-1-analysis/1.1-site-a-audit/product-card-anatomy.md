# Анатомия карточки товара (сайт А)

Это референс для этапов 2 (структура), 3 (дизайн) и 4 (перенос контента). Пример разбора — карточка «Борей, СК (150 г/л + 50 г/л)».

## Блоки карточки

### 1. Хлебные крошки
Главная → Каталог продукции → Категория → Название товара

### 2. Заголовок H1
Полное название с концентрацией действующего вещества (обязательно, важно для агронома).

### 3. Соцшаринг
Telegram, ВКонтакте, Одноклассники, WhatsApp, Viber, «Скопировать ссылку». **На сайте Б оставить, обновив состав** (например, добавить Rutube/Дзен, убрать Одноклассники, если аудитория не использует).

### 4. Медиа-блок
- Главное фото упаковки (одно, крупное)
- Возможна галерея (не проверено — на данной карточке одно фото)

### 5. Ценовой блок
- Цена ₽/л (или ₽/кг)
- Статус наличия («В наличии»)
- Кнопка «Купить»
- Раскрывающийся телефон «+7 (351) 750...»

### 6. Структурированные характеристики
Табличная форма «параметр → значение»:
- Производитель
- Страна производства
- Тип (органические / неорганические)
- Вид (инсектицид / гербицид / …)
- Действие на организм (кишечное, контактное, системное)
- Культура (список)
- Способ применения (опрыскивание, полив, обработка семян и т. д.)
- Вредный объект (список вредителей/сорняков/болезней)
- Форма выпуска (СК, ВДГ, КЭ и т. д.)
- Упаковка (канистра, флакон)
- Срок применения (в период вегетации и т. д.)
- Характер действия (избирательный / сплошной)
- Размеры упаковки
- Способ упаковки (детально: «Канистра 5 л, флакон 1 л»)

### 7. Описание
Маркетинговый текст 2–4 абзаца: что это, для кого, ключевые преимущества (списком).

### 8. Регламент применения
Таблица (обязательный агрономический материал):
- Культура → Вредитель/сорняк → Норма расхода, л/га (или кг/га)
- Срок ожидания и кратность обработки
- Расход рабочей жидкости

### 9. Особенности применения
- Рекомендации по применению
- Ограничения (например: «высокоопасен для пчёл, погранично-защитная зона не менее 4–5 км»)
- Приготовление рабочего раствора (пошагово)
- Значение pH воды
- Физико-химическая совместимость с другими препаратами (иногда с таблицей)

### 10. Описание действующего вещества
- Характеристика веществ (химический класс, механизм)
- Механизм действия
- Скорость воздействия
- Период защитного действия
- Особенности препарата
- Фитотоксичность

### 11. Хранение и упаковка
- Срок хранения
- Упаковка
- Условия хранения (температура)
- Класс опасности **для здоровья** (по ГОСТ 12.1.007 / ГН 1.2.3111-13, шкала 1–4; например: «3-й класс опасности для человека»)

### 11а. Условия доставки ⚠️ (новый блок для сайта Б, отсутствовал на сайте А)

Обязательный блок, требующий явного визуального акцента. Для каждого товара должно быть указано:

- **Класс опасности при перевозке** (по ДОПОГ/ADR): 3, 6, 9 или без класса
- **Доступные способы получения:**
  - «✓ Доставка ТК по РФ + самовывоз из Челябинска» — для препаратов без класса опасности перевозки или класса 9
  - «⚠ Только самовывоз из Челябинска» — для препаратов класса 3 (легковоспламеняющиеся жидкости) или класса 6 (токсичные)

**Почему это критично:**
Клиент должен видеть возможности доставки **до** оформления заявки, а не выяснять после. Иначе — фрустрация, отказы от заказов и негатив.

**Как реализовать в дизайне:**
- Значок/бейдж в шапке карточки рядом с ценой (быстрый визуальный сигнал).
- Подробности — в блоке «Условия доставки» с пояснением про класс опасности перевозки.
- В корзине: если добавлен товар «только самовывоз» — при оформлении заявки автоматически ограничивать выбор способа получения.
- На листинге категорий: значок «только самовывоз» рядом с товарами класса 3/6, чтобы клиент видел ограничение ещё до открытия карточки.

### 12. Первая помощь при отравлении ⚠️ (обязательный блок)
- При случайном проглатывании
- При попадании на кожу
- При попадании в глаза
- При первых признаках отравления
- Информация для врача (симптоматическое лечение, антидоты)
- Контакт токсикологического центра (адрес, телефон, часы работы)

### 13. Транспортировка, утилизация
- Меры безопасности при транспортировке и применении (ссылки на ГОСТ, СанПиН)
- Обезвреживание пролитого пестицида
- Утилизация тары
- Ограничения по применению (например: запрещено в ЛПХ, авиаспособом)

### 14. Охрана окружающей среды
- Защита пчёл
- Рыбохозяйственная оценка
- Ограничения в санитарных зонах

### 15. Итоговый маркетинговый абзац
С внутренней перелинковкой на смежные категории/товары.

### 16. Cross-sell
- Блок «Смотрите также» с тегами
- Ссылка «Условия возврата и обмена»

## Что это значит для сайта Б

**Ключевой вывод:** карточка товара — это паспорт продукта с ~16 полноценными блоками (после добавления «Условий доставки»), включая **юридически значимые разделы** (первая помощь, класс опасности, охрана среды) и **коммерчески значимые** (условия доставки в зависимости от класса опасности перевозки). Терять эту структуру нельзя.

**Требования к дизайну карточки на сайте Б:**
1. Все блоки, включая новый «Условия доставки», должны быть сохранены и добавлены.
2. Первая помощь и меры безопасности визуально выделены (иконки, цветовой акцент).
3. **Класс опасности перевозки и способы получения товара — виден сразу**, рядом с ценой (бейдж «Доставка ТК» / «Только самовывоз»).
4. Регламент применения — вынести близко к началу карточки (после характеристик).
5. Табличные данные (характеристики, регламент) — адаптивные, на мобильных читаются комфортно.
6. Якорные ссылки к разделам карточки (длинная страница, навигация критична).
7. Быстрая кнопка «Заказать / Запросить консультацию» — sticky при скролле.
8. Уместные CTA: «Скачать инструкцию по применению» (PDF), «Заказать пробную партию», «Позвонить агроному».

**Требования к переносу на этапе 4:**
- Автоматизированный парсинг всех 91 карточки с сайта А необходим.
- Ручной ввод исключён (объём слишком большой, риск ошибок).
- Каждую карточку нужно сверить: производитель, действующее вещество, класс опасности, первая помощь — не должны исказиться при миграции.

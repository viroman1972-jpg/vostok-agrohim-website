- **~10 инфостраниц** → перенос + переработка

- **4 статьи** → перенос
- **6 отзывов** → перенос как «социальное доказательство»
- **~15+ тегов** → создать посадочные страницы для SEO
- **2 прайс-листа** → скачать, при необходимости обновить, разместить

**Оценка объёма** (для планирования этапа 4): ~110 сущностей, значительная часть — трудоёмкие карточки товаров.

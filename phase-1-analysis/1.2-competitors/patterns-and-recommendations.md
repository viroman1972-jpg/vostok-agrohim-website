# Паттерны конкурентов и рекомендации для сайта Б

**Дата:** 09.07.2026
**Основа:** 4 прямых конкурента (АГРООПТ, ФитоПро, Янкина Агро, Агрошоп24) + 2 UX-эталона (Щёлково Агрохим, Август).

Документ структурирован по критериям, согласованным на 1.1: каталог/карточка, доставка и работа с классами опасности, разделение B2B/B2C, позиционирование и доверие, формы и обработка ПДн.

## 1. Каталог: паттерны и что забирать себе

### Что делают все

- **Категории по типу препарата** (гербициды/инсектициды/фунгициды/протравители и т. д.) — базовая ось, есть у всех, есть и у сайта А.
- **Отображение действующего вещества** прямо в листинге (не только в карточке) — Щёлково Агрохим показывает д. в. + концентрацию прямо под названием товара. Восток АгроХим этого **не делает** — теряет ценность для агронома, который выбирает по д. в.

### Что делают лучшие (Щёлково Агрохим, ФитоПро)

- **Каталог по культурам** — второй, полностью независимый вход в каталог. ФитоПро: 10 культур в меню, каждая = отдельный лендинг «Защита [культуры]». Щёлково: 34 культуры. У сайта А **этого нет вообще** — это одна из самых больших упущенных возможностей.
- **Каталог по вредным объектам** — Щёлково даёт вход «Против болезни X», «Против вредителя Y», «Против сорняка Z» с фильтрацией. У сайта А **этого нет**.
- **Каталог по действующим веществам** — тоже отдельный вход у Щёлково. Отдельно ценно для профессиональных агрономов и B2B-клиентов, которые ищут аналоги.
- **Мощные фильтры**: не «дешевле-дороже», а «против такого-то вредителя», «для такой-то культуры», «действующее вещество», «упаковка».

### 🎯 Рекомендация для сайта Б

Ввести **4 параллельных входа в каталог**:
1. По типу препарата (базовый)
2. **По культурам** — минимум 15–20 главных культур для нашего сегмента (пшеница озимая/яровая, ячмень, кукуруза, подсолнечник, соя, рапс, свёкла, картофель, овощные, сад, виноград)
3. **По вредным объектам** — упрощённо на старте: сорняки / вредители / болезни, а внутри — 10–15 типовых наиболее распространённых
4. **По действующим веществам** — простой алфавитный список, но с фильтрами по типу препарата

Фильтр каталога должен включать: культура + вредный объект + действующее вещество + упаковка (5 л / 10 л / 1 л / т. д.) + производитель + новинка.

**У Восток АгроХим уже есть теги** (Торнадо, Магнум, Лазурит и т. д.) — их можно использовать как посадочные страницы по препаратам и по д. в.

## 2. Карточка товара: что забрать себе

Хорошая новость: **карточка на сайте А уже сильная** (~15 блоков, включая юридически значимые). Это не типичная ситуация — у конкурентов карточки обычно проще. Но есть чему поучиться.

### Что хорошо у Щёлково Агрохим и Август
- **Действующие вещества с концентрацией на превью** — сразу видно в листинге, не нужно кликать.
- **Краткое описание в 1–2 фразы** прямо под названием — суть препарата понятна с первого взгляда.
- **Метки:** «Новинка», «Расширение регистрации», акции — визуальные бейджи.

### 🎯 Рекомендации для сайта Б
1. Все ~15 блоков сайта А **сохраняем** (это уже описано в анатомии карточки, 1.1).
2. **Добавляем** новый блок «Условия доставки» с классом опасности перевозки (ДОПОГ), критично именно для нас (в 1.1 уже зафиксировано).
3. **В листинге** показываем д. в. с концентрацией — учимся у Щёлково. Клиенту это ускоряет выбор.
4. **Визуальные бейджи:** «Новинка», «Хит», «Только самовывоз» (для класса 3/6), «Есть в наличии», «Доступен ФГИС Сатурн» (сертификация ниже).
5. **Sticky-CTA** (закреплённая кнопка «Заказать / Позвонить директору») — карточка длинная, кнопка должна ехать со скроллом.

## 3. Доставка и работа с классами опасности

### Что делают конкуренты

- **ФитоПро:** доставка СДЭК и «Деловые Линии», бесплатная от 100 000 ₽, срок от 2 рабочих дней. Про классы опасности перевозки — **ничего**. «Самовывоз возможен по согласованию с менеджером» — то есть модель как у Восток АгроХим (не всё можно отправить ТК), но **явно не описана** на сайте.
- **АГРООПТ:** отдельная страница «Доставка», но детали не открыл.
- **Никто явно не пишет про ДОПОГ-классы** в контексте, «что можно / что нельзя отправить ТК». Это стандартная слепая зона отрасли.

### 🎯 Рекомендация для сайта Б — **это наше УТП**

Мы делаем то, что не делает никто:
1. **На карточке каждого товара** — бейдж рядом с ценой: «✓ Доставка ТК по РФ» или «⚠ Только самовывоз (кл. опасности перевозки 3/6)».
2. **На листинге категории** — тот же бейдж мелким шрифтом рядом с ценой.
3. **Отдельная страница «Доставка»** — с явным разделом «Что нельзя отправить ТК» и почему (класс опасности по ДОПОГ, требования к перевозке пестицидов).
4. **В корзине** — при попытке добавить товар с кл. опасности 3/6 показывается плашка: «Этот препарат отправляется только самовывозом из Челябинска». При смешанной корзине — предлагается разбить заказ или выбрать самовывоз для всей корзины.

**Транспортные компании, которые нужно упомянуть на сайте:** ПЭК (подтверждена по отзывам сайта А), плюс уточнить у заказчика полный список. Конкуренты называют СДЭК и «Деловые Линии» — стоит рассмотреть добавление.

## 4. B2B / B2C: как разделяют конкуренты

### Наблюдение

- **ФитоПро:** есть отдельный лендинг «Опт» (`/opt`), где чётко перечислено, для кого он: КФХ от 100 га, агрохолдинги, тепличные комплексы, дистрибьюторы, питомники. При этом основной сайт остаётся общедоступным.
- **Янкина Агро:** жёсткое B2B-only — «стандартные фасовки, мелкие заказы не выполняются».
- **АГРООПТ:** розница вынесена на отдельный домен `alexagro.com`, оптовый сайт — самостоятельный.
- **Щёлково Агрохим:** отдельный поддомен `dacha.betaren.ru` для дачников, основной сайт — для профессионалов.

### 🎯 Рекомендация для сайта Б

Учитывая ОКВЭД 46.75.1 (опт) и подтверждённую основную модель (самовывоз оптовыми партиями), но при этом реальную работу с физлицами (подтверждена по отзывам):

**Одноуровневый сайт с приоритетом B2B**, а не два разных сайта или два поддомена (нецелесообразно для нашего масштаба).

Реализация:
- **Главная — B2B-first.** Первый экран говорит с оптовым покупателем: «Оптовый поставщик СЗР по всей России с 2011 года. Прямой контакт с директором».
- **Отдельная посадочная страница «Опт»** — по образцу ФитоПро: для кого, условия, документы для юрлиц, отсрочка платежа (если возможна), схема работы.
- **Отдельный блок / посадочная страница «Для дачников и небольших хозяйств»** — с честной коммуникацией: «Работаем и с частными покупателями. Минимальные объёмы, оплата по факту, отправляем через ТК (если препарат не 3/6 класса)».
- Каталог **один и тот же**, но карточка адаптирована: показывает цены за литр и стоимость минимальной фасовки. Скидка при больших объёмах — плашкой прямо в карточке.

## 5. Позиционирование и доверие

### Что делают конкуренты хорошо

- **ФитоПро:** «Оригинальные препараты от официальных дистрибьюторов Syngenta, BASF, Август, ФМРус, Листерра». Явное перечисление брендов = доверие.
- **АГРООПТ:** «14+ производителей семян» с логотипами — то же самое.
- **Щёлково Агрохим:** мировой рекорд по озимой пшенице, программа лояльности, работа с вузами, мобильное приложение, свой журнал — весь набор корпоративного доверия.
- **ФитоПро:** «Полный пакет документов для ФГИС Сатурн на каждую партию» + «Работаем с юрлицами / ИП / КФХ по б/н» + «Отсрочка платежа» — конкретные фразы, которые B2B-клиенту нужно услышать.

### Чего критично не хватает у сайта А

- Реквизиты юрлица не указаны в футере (по данным 1.1). Конкуренты типа АГРООПТ (ООО «АГРООПТ», ОГРН 5167746200364) явно ставят их в футере — это стандарт доверия.
- Не показаны бренды-партнёры (Август, Байер, ФМРус, Листерра — с сайта А видно, что они с ними работают, но логотипы не выведены).
- Нет упоминания ФГИС «Сатурн» — а это обязательное для B2B-клиента.

### 🎯 Рекомендация для сайта Б

Обязательные блоки на сайте Б для доверия:

1. **Полные реквизиты юрлица в футере** — ООО «Восток АгроХим», ИНН, ОГРН, юр. адрес, телефон, email.
2. **Логотипы брендов-партнёров** на главной (Август, Байер / БАСФ / ФМРус / Листерра — то, что действительно возят).
3. **Явное упоминание «Работаем с ФГИС Сатурн» / «Полный пакет документов»** — на главной, на странице «Опт», в футере.
4. **«На рынке с 2011 года. 15+ лет опыта»** — фиксированное послание на первом экране.
5. **Персонализация через директора:** фото Прутяна А. В., «Прямой контакт с директором», цитата от первого лица — на главной, «О компании», «Контакты». Это то, чего нет ни у одного конкурента.
6. **Раздел «Отзывы»** — 6 существующих отзывов с сайта А + активная механика сбора новых (форма отзыва после покупки).
7. **Раздел «Сертификаты и документы»** — сертификаты на препараты, декларации соответствия, документы ФГИС Сатурн. АГРООПТ вынес это в отдельную страницу.
8. **Опционально: рейтинг Яндекс.Справочника** — виджет в футере как у АГРООПТ.

## 6. Формы и обработка ПДн

### Что делают конкуренты

- **ФитоПро:** явное согласие на ПДн в форме входа: «Я выражаю согласие на обработку персональных данных в соответствии с Политикой конфиденциальности (согласно категориям и целям, поименованным в п. 4.2.2-4.2.3)» — с явными ссылками на Политику. Это правильно.
- **Щёлково Агрохим:** «Нажимая на кнопку, вы соглашаетесь на обработку персональных данных и подтверждаете, что ознакомлены с политикой конфиденциальности» — во всех формах.
- **АГРООПТ:** Cookies-баннер + отдельные страницы Политика конфиденциальности + Оферта + Пользовательское соглашение.

### 🎯 Рекомендация для сайта Б

1. **Все формы** (обратная связь, оформление заказа, подписка) содержат чекбокс согласия на ПДн со ссылкой на Политику. Это требование 152-ФЗ (детальный разбор — на этапе 1.4).
2. **Cookies-баннер** с явными кнопками «Принять» / «Только необходимые» / «Настроить». На сайте А сейчас только «Принять», это уходит в прошлое (детальный разбор — на 1.4).
3. **Обязательные правовые страницы:**
   - Политика в отношении обработки ПДн
   - Согласие на обработку ПДн (текст согласия — отдельно)
   - Пользовательское соглашение
   - Публичная оферта
   - Cookies-политика
4. **Формы должны:** записывать источник заявки (какая страница), номер класса опасности товара в корзине, вид клиента (юрлицо/физлицо) — для маршрутизации директору правильной информации.

## 7. Каналы связи и мессенджеры

### Что стало отраслевым стандартом

- **Обязательно:** телефон + email + WhatsApp + Telegram
- **Часто:** VK, VK Marketplace (для e-commerce), YouTube-канал
- **Появляется:** мессенджер **MAX** (агрегаторы явно ставят в шапке — есть у АГРООПТ и Щёлково)
- **Отдельные страницы:** «Задать вопрос», «Заказать звонок», «Как нас найти?»

### 🎯 Рекомендация для сайта Б

Обязательный набор каналов в шапке и футере:
- Телефон (кликабельный на мобильных)
- Email
- WhatsApp
- Telegram
- MAX (появляется в отрасли, полезно быть первыми)
- Заказать звонок (модалка)

Оптимально — все они ведут в одно место (директор), но с автоответом, задающим ожидания времени ответа (см. решение о моно-контакте от 09.07 в журнале решений).

## 8. Каталог/навигационные фичи, которых нет ни у кого

По итогам разбора выделяются функции, которые улучшат UX и потенциально дадут конкурентное преимущество:

1. **«Подбор препарата по задаче»** — визарды типа «У меня [культура]. Проблема [сорняки / вредители / болезни]. Что мне купить?» → выдача препаратов. Ни у одного из разобранных сайтов подобное не сделано хорошо (даже у Щёлково это разбросано по фильтрам).
2. **Прозрачные условия по классам опасности перевозки** (см. выше) — наше уникальное УТП.
3. **Прямой контакт с директором** — есть только у нас.
4. **Онлайн-чат с реальным ответом от менеджера** (а не бот) — не встречается у конкурентов.
5. **Калькулятор нормы расхода** прямо в карточке товара («введите площадь → узнайте, сколько нужно»). Ни у кого не видел.

## Итог: что взять, что не брать, что сделать своим

### Забрать (стандарты доверия и удобства, которых нет на сайте А):
- Полные реквизиты в футере
- Логотипы брендов-партнёров
- Полный правовой пакет (Оферта + Соглашение + Политика ПДн + Cookies)
- Явное согласие на ПДн в формах
- Мультиканал связи (WhatsApp, Telegram, MAX)
- Каталог с параллельными входами: тип препарата + культура + вредный объект + действующее вещество
- Мощные фильтры в каталоге
- Отображение действующих веществ прямо в листинге
- Отдельная страница «Опт»
- ФГИС «Сатурн» как явный benefit

### Не брать (перегруз, не наш масштаб):
- Собственный журнал (Щёлково) — избыточно для дистрибьютора
- Мобильное приложение — избыточно для этапа 1
- Программа лояльности с личным кабинетом уровня Щёлково — избыточно на старте (можно позже)
- Международные версии — не наш кейс
- «Академия для вузов» — не наш кейс

### Своё уникальное (наши УТП):
1. **Прозрачность по классам опасности перевозки** — визуально явно в каталоге и на карточке.
2. **Прямая работа с директором** — фото, имя, персональные ответы.
3. **15+ лет на рынке (с 2011 года)** — активно использовать в позиционировании.
4. **Работа и с юрлицами, и с физлицами** — отдельные посадочные страницы, но один каталог.
5. **Подбор препарата по задаче** — визард для клиента, который «не знает как гуглить».
6. **Калькулятор нормы расхода** в карточке.

Эти шесть пунктов — то, что должно попасть в бриф на дизайн (этап 3) как обязательные фичи сайта Б.

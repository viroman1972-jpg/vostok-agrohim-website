# Шортлист конкурентов для анализа

**Дата:** 09.07.2026
**Метод отбора:** поиск по запросам «дистрибьюторы СЗР Россия», «оптовый поставщик агрохимии», исключение узкорегиональных игроков без ассортиментной глубины.
**Отобрано:** 6 сайтов — 4 прямых конкурента-дистрибьютора и 2 сайта производителей-лидеров как UX-эталоны.

## Прямые конкуренты (дистрибьюторы СЗР)

### 1. АГРООПТ — agroopt-market.ru
- **Специализация:** проф. семена + СЗР (СЗР — вторичный каталог)
- **География:** Москва (склад в Хорошевском р-не), доставка по РФ
- **Юрлицо:** ООО «АГРООПТ», ОГРН 5167746200364 (виден в футере — соответствует практике)
- **Платформа:** InSales (SaaS)
- **Каналы:** телефон 2 номера + email + WhatsApp + Telegram + **MAX** + VK + YouTube + Yandex.Sprav рейтинг
- **Ключевые страницы:** «Как заказать», «Прайс-лист», «Сертификаты», «Оплата», «Доставка», «Оригинальная упаковка», «Где мой заказ», «Задать вопрос», «Статьи», «Помощь при выборе», «Гарантии», «Вакансии»
- **Правовые страницы:** Политика конфиденциальности + Публичная оферта + Пользовательское соглашение — **полный правовой пакет**
- **Оплата:** отображение платёжных систем в футере (Мир, Visa, Mastercard)

### 2. ФитоПро — fitopro23.ru
- **Специализация:** СЗР и агрохимия (профильный B2B-опт для сельхозпроизводителей)
- **География:** Краснодарский край, поставки по всей РФ через СДЭК и «Деловые Линии»
- **Юрлицо:** ИНН 614707544220 в футере (это ИП, а не ООО — 12 цифр)
- **Платформа:** заказная разработка (студия Мегагрупп)
- **Каналы:** телефон + email + WhatsApp + Telegram (личный кабинет, регистрация)
- **⭐ Ключевые сильные стороны:**
  - **Каталог по культурам** отдельным входом в навигации (10 культур)
  - **Полноценный лендинг «Опт»** с FAQ, шагами оформления, условиями для сегментов клиентов
  - **ФГИС «Сатурн»** как ключевой benefit — обязательная гос. система маркировки пестицидов
  - Работа с юрлицами / ИП / КФХ по б/н, отсрочка платежа для постоянных клиентов
  - Бесплатная доставка от 100 000 ₽
- **Слабое:** нет раскрытых реквизитов ООО, слабая соц. страница

### 3. Янкина Агро — yankina-agro.ru
- **Специализация:** классический дистрибьютор (Агропланта, БАСФ, Дюпон, Кеминова, Агрокеми, АгроРус)
- **Позиционирование:** «стандартные фасовки, мелкие заказы не выполняются» — чисто B2B, без розницы
- **Услуги:** цены за 1 л/1 кг, скидки за объём, доставка по РФ
- Разбор ограничен снимком в выдаче (сайт даёт мало) — для полного разбора нужна регистрация. Отмечаю как консервативный «классический» стиль.

### 4. Агрошоп24 — xn--24-6kcm9cahf7e.xn--p1ai
- **Специализация:** B2B для профессионального сегмента (питомники, теплицы, садовые центры, КФХ), в т. ч. **и агрохимия оптом**
- **Модель отгрузки:** **самовывоз + доставка по Москве + отправка ТК в регионы** — по описанию максимально близко к модели Восток АгроХим
- **Особенности:** позиционирование через «работу под сезонные пики и технологические окна», «подбор позиций под культуру и задачу»
- **Разбор ограничен:** robots.txt заблокировал автоматический фетч. Профиль восстановлен из поискового снимка.

## UX-эталоны (сайты производителей)

### 5. Щёлково Агрохим — betaren.ru
- **Тип:** сайт производителя-лидера (не e-commerce)
- **Юрлицо:** АО «Щёлково Агрохим»
- **⭐ Референсные фичи:**
  - **Каталог по 4 срезам:** по типу препарата, **по культурам** (34 культуры), **по вредным объектам** (болезни/вредители/сорняки), **по действующим веществам**
  - **Мощнейший фильтр** в каталоге: выбор культуры → перечень болезней/вредителей/сорняков → список действующих веществ (100+ позиций)
  - **Отдельный раздел «Агросправочник»** — база знаний по вредителям, болезням, сорнякам, действующим веществам
  - **Собственный журнал** «Betaren Agro» (ежемесячный, архив 5+ лет)
  - **Мобильное приложение** для iOS, Android, Huawei, RuStore
  - **Программа лояльности** для клиентов
  - **Работа с вузами** через «Бетарен Академию»
  - **Международный переключатель** стран (модалка «We suggest you visit the English version»)
  - **Мультиканал соцсетей:** MAX, Telegram, VK, Дзен, RuTube, VK Video
- Оговорка: без цен, без корзины. Это корпоративный сайт производителя, продажи — офлайн через дистрибьюторов.

### 6. Август — avgust.com (не фетчил, оценка из отраслевой практики)
- Крупнейший отечественный производитель СЗР. Сайт — эталон по подаче культур и структурированной карточке товара. Как UX-эталон учитываю в патернах.

## Кого не взял и почему

- **UPL Россия** (upl-ltd.ru) — производитель, но менее релевантный для дистрибьюторской модели.
- **Агросорос Трейд** (agrosoros.com) — сильный игрок, но специфический региональный фокус (Центральный регион) + фишка «СЗР дронами» — не наш кейс.
- **ГК Агро СОС** (agro-sos.ru) — оптовик и розничный магазин, но по описанию похож на АГРООПТ, дублирование.
- **Syngenta, BASF, Bayer** — иностранные производители, ушедшая или пересобранная в РФ модель; референс дают, но не для нашего типа сайта.

Итого: 4 прямых конкурента + 2 UX-эталона = 6 сайтов, покрывающих спектр от локального дистрибьютора до федерального производителя.

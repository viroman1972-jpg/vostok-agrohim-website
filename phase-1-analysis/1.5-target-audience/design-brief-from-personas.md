## 1. УТП × Персона: матрица приоритетов

| УТП | Иван Петрович (агроном) | Николай Александрович (фермер) | Сергей Валерьевич (дистрибьютор) | Алевтина Викторовна (дачник) |
|---|:---:|:---:|:---:|:---:|
| Прямой контакт с директором | 🔥🔥 | 🔥🔥🔥 | 🔥🔥🔥 | ○ |
| 15+ лет на рынке | 🔥🔥🔥 | 🔥 | 🔥🔥🔥 | ○ |
| Прозрачные условия доставки | 🔥🔥 | 🔥🔥 | 🔥🔥 | ○ |
| B2B + B2C одновременно | 🔥 | 🔥🔥 | 🔥🔥🔥 (B2B only) | 🔥🔥🔥 (B2C only) |
| Подбор препарата по задаче | ○ | 🔥🔥 | ○ | 🔥🔥🔥 |
| Калькулятор нормы расхода | ○ | 🔥 | ○ | 🔥🔥🔥 |

**Что читается из матрицы:**

1. **Прямой контакт с директором** — общий триггер для всех B2B-персон, слабее для B2C. Значит это УТП №1 в главном коммуникационном сообщении сайта.
2. **15 лет на рынке** — сигнал доверия, критичен для «серьёзных» персон (агроном, дистрибьютор), но не для фермера и не для дачника.
3. **Прозрачные условия доставки** — универсальный B2B-триггер, ниже для дачника (он в основном самовывозом или почтой).
4. **Подбор по задаче + калькулятор** — почти исключительно B2C-инструменты. Не тратим фокус B2B-разделов на них.
5. **B2B/B2C-разделение** — критично: дистрибьютор ждёт «только B2B», дачник — «отдельно от промышленных». Разделение посадочных = ключевая структурная решение.

## 2. Ранжирование персон и посадочные страницы

По приоритету и по объёму денег в кассе:

1. **Николай Александрович (фермер)** — самая частая и доступная целевая, и по объёму бизнеса, и по количеству возможных заказов. Главная страница должна говорить в первую очередь **с ним**.
2. **Сергей Валерьевич (дистрибьютор)** — редкий, но крупный клиент. Отдельная посадочная страница `«Опт / Дистрибьюторам»`.
3. **Иван Петрович (агроном)** — есть, но реже. Работает и с главной, и с каталогом напрямую. Отдельной посадочной не нужно.
4. **Алевтина Викторовна (дачник)** — вторичный, но заметный сегмент. Отдельная посадочная страница `«Для дачи / малых хозяйств»`.

**Итого посадочных, которые точно нужны:**
- Главная — общий вход, ориентирована на B2B-фермера как основного пользователя.
- Каталог — универсальный вход по всем 4 срезам (тип препарата / культура / вредный объект / действующее вещество).
- **«Опт / Для дистрибьюторов»** — под персону 3.
- **«Для дачи»** — под персону 4.
- Карточка товара — с переключателем «Для агронома / Для дачника» (решение 09.07.2026).
- Служебные страницы: «О компании», «Контакты», «Доставка», «Гарантии и претензии», «Документы».

Если у вас в севообороте есть подсолнечник — уточните: препарат имеет последействие. Позвоните, разберёмся вместе.» | «Заходите в личный кабинет для получения индивидуального предложения» |

Отдельно: **тон директора-персоны** должен звучать в подписях и в блоках «От первого лица». Это часть УТП «прямой контакт с директором». Формулировки: «Отвечу лично — Прутян Андрей», «Работаем с 2011 года. За 15 лет ни разу не подвели клиента — если что-то пойдёт не так, разбираюсь лично».

## 4. Устройства и адаптив: приоритеты

Критично для брифа на этап 3 (дизайн):

- **Николай (фермер) — mobile-first.** Смотрит преимущественно со смартфона. Значит **мобильная версия — приоритет 1**. Все ключевые сценарии (открыть карточку, посмотреть цену, написать в WhatsApp) должны работать одним пальцем.
- **Алевтина (дачник) — mobile, с крупным шрифтом.** Пожилой пользователь = большой шрифт (минимум 16px для базового текста, 18–20px предпочтительно), крупные тап-цели (минимум 44×44 пикселя).
- **Сергей (дистрибьютор) — desktop.** Смотрит с ноутбука в офисе. Для него важна информационная плотность (реквизиты, условия — сразу все видны).
- **Иван (агроном) — mixed.** И десктоп в кабинете, и мобильный на планёрке. Универсальный подход.

**Вывод для брифа:** дизайним **mobile-first, но с сильным desktop-опытом для страницы «Опт»** (там дистрибьютор ждёт плотной информации).

## 5. Каналы связи, приоритетные к выведению в UI

Из персон:

- **WhatsApp** — используют все 4 персоны в разной степени (наибольше — фермер). Обязательная кнопка на всех страницах.
- **Telegram** — B2B (агроном, фермер, дистрибьютор). Обязательно.
- **Звонок** — все 4 персоны. Обязательно, кликабельный на мобильных.
- **Email** — B2B, для документов. Обязательно.
- **MAX** — стандарт отрасли (стал появляться у Щёлково, АГРООПТ), но по нашим персонам не критичен. Добавляем как «модный», но не первым в списке.
- **Форма обратной связи** — must have, но не главный канал. Все персоны предпочтут прямой контакт.
- **Онлайн-чат с реальным человеком** — можно рассмотреть, если есть ресурс (по решению о моно-контакте — сложно, чат директор сам вести не сможет). Пока не приоритет.

**Приоритетная кнопка на всех страницах:** «Получить консультацию» — с выбором канала (WhatsApp / Telegram / звонок / форма) в модальном окне. Это буквально овеществление УТП №1.

## 6. Приоритетные сценарии для этапа 2 (проектирование User Flows)

Из типовых сценариев персон формируется список **user flows**, которые нужно проработать на этапе 2:

1. **«Фермер быстро оформляет заявку на препарат по названию»** — mobile, максимум 3 экрана от посадки до отправки заявки.
2. **«Дачник находит препарат по проблеме»** — Яндекс → блог/карточка → переключатель «Для дачника» → покупка малой фасовки.
3. **«Агроном сверяет ассортимент и оформляет объёмный заказ»** — десктоп, каталог → сравнение → счёт на юрлицо.
4. **«Дистрибьютор изучает условия опта и делает первую пробную поставку»** — десктоп, «Опт» → прайс → звонок директору → договор.
5. **«Клиент проверяет статус заказа»** — все персоны, страница «Где мой заказ» с трекингом.
6. **«Клиент подаёт претензию»** — все персоны, отдельная форма → к директору.

## 7. Что снимает страхи и возражения

По каждой персоне выделим один-два блока сайта, снимающих её главные страхи:

| Персона | Главный страх | Что должно быть на сайте |
|---|---|---|
| Агроном | Препарат не пришёл в срок | Явный статус наличия + сроки самовывоза / доставки ТК |
| Фермер | Куплю не то, деньги на ветер | Кнопка «Спросить директора» + подбор по задаче + отзывы фермеров |
| Дистрибьютор | Мутный поставщик, проблемы с документами | Реквизиты в футере + страница «Документы» с образцами + рег. номер РКН, ФГИС и т.п. |
| Дачник | Отравлю растения / семью / себя | Понятные инструкции, дачное представление карточки, блоки безопасности с иконками |

## 8. Ключевые сообщения первого экрана главной страницы

По итогам всего анализа, вот **предлагаемый набор сообщений для первого экрана** (на согласование заказчиком, финализация — на этапе 3):

**Основное сообщение (H1):**
> «Оптовый поставщик СЗР и агрохимии по всей России. Работаем с 2011 года — прямо с директором.»

**Подзаголовок:**
> «Средства защиты растений от Август, Байер, БАСФ, Щёлково Агрохим, ФМРус и других — со склада в Челябинске и с доставкой ТК по РФ.»

**CTA-блок:**
- Основной: «Получить консультацию» (WhatsApp / Telegram / звонок)
- Вторичный: «Открыть каталог»
- Третий: «Скачать прайс» (для быстрого доступа дистрибьюторов и агрономов)

**Пруф-блок (сразу под первым экраном):**
- 15+ лет на рынке
- 91+ SKU в каталоге
- Работаем с юрлицами, ИП, КФХ, физлицами
- Прямые контракты с производителями

**Явный переключатель под первым экраном:**
- «Я оптовый покупатель» → страница «Опт»
- «Я дачник / для дома» → страница «Для дачи»

Это разделение снимает главное возражение дистрибьютора («это точно для нас?») и дачника («это точно про меня?»).

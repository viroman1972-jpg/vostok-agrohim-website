# Дельта-промпт: единая навигация на всех страницах (ДМ34)

**Затрагивает три файла** в `phase-3-design/3.3-mockups/`:
- `Hero.dc.html` (главная)
- `catalog-listing-gerbicidy.dc.html` (листинг категории)
- `Product_card_balerina.dc.html` (карточка товара)

**Тип изменения:** унификация навигации, без правок визуального стиля
**Дата:** 17.08.2026
**Решения:** ДМ34 (единая шапка), У07 («Полезное» убрано), П08 (переклассифицирован — переносить нечего)

---

## Зачем

Главная и внутренние страницы разошлись по навигации:

| | Главная | Листинг и карточка |
|---|---|---|
| Пункты шапки | Как мы работаем · Задачи защиты · **Каталог ▾** · Производители · Контакты | Каталог · **О компании** · **Полезное** · Контакты |
| Каталог | мегаменю: 7 категорий + 3 входа | простая ссылка |
| Телефоны | два (директор + офис) | один |

С карточки товара нельзя перейти в другую категорию, не возвращаясь на главную. Посетитель видит два разных сайта. Футеры при этом уже идентичны — их структуру не трогаем.

---

## Целевая шапка (одинаковая на всех трёх страницах)

**Каталог ▾** · Задачи защиты · Как мы работаем · Производители · Контакты

Правила:
1. **«Каталог» — первый пункт.** Сайт-витрина, каталог — основной сценарий. На главной он сейчас в середине, передвинуть в начало.
2. **Мегаменю каталога — на всех страницах.** Раскрывается по наведению, содержит 7 категорий и 3 параллельных входа (см. состав ниже). На листинге и карточке сейчас простая ссылка — заменить на мегаменю, точно такое же, как на главной.
3. **Телефоны — оба, на всех страницах:** `+7 (922) 750-09-20` (директор, крупнее, с иконками Telegram и MAX) и `+7 (351) 750-09-20` с подписью «офис» — блоком, как на главной.
4. **Пункты «Полезное» и «О компании» из шапки удаляются.**

### Состав мегаменю (без изменений, как на главной)

Категории: Гербициды `/catalog/gerbitsidy/` · Инсектициды `/catalog/insektitsidy/` · Фунгициды `/catalog/fungitsidy/` · Протравители `/catalog/protraviteli/` · Стимуляторы роста `/catalog/stimulyatory-rosta/` · Адьюванты `/catalog/adyuvanty/` · Десиканты `/catalog/desikanty/`

Параллельные входы: По культурам `/catalog/kultura/` · По вредителям, сорнякам и болезням `/catalog/vrednyy-obekt/` · По действующим веществам `/catalog/dv/`

### Адреса пунктов-якорей

| Пункт | На главной | На листинге и карточке |
|---|---|---|
| Задачи защиты | `#tasks` | `/#tasks` |
| Как мы работаем | `#how-we-work` | `/#how-we-work` |
| Производители | `#manufacturers` | `/#manufacturers` |
| Контакты | `/contacts/` | `/contacts/` |

На главной пункты скроллят по странице, на внутренних — ведут на главную с якорем. Механика уже работает в футерах внутренних страниц.

## Изменение 1 — `Hero.dc.html` (главная)

### 1а. Порядок пунктов в шапке

Сейчас: «Как мы работаем · Задачи защиты · Каталог ▾ · Производители · Контакты».
Стало: **«Каталог ▾ · Задачи защиты · Как мы работаем · Производители · Контакты»**.

Блок мегаменю (`<div style="position:relative;" onMouseEnter=... onMouseLeave=...>`) переносится в начало `<nav>`, перед остальными пунктами. Внутреннее устройство мегаменю не меняется.

Заодно проставить рабочие якоря вместо заглушек `href="#"`:
- «Задачи защиты» → `#tasks`
- «Как мы работаем» → `#how-we-work`
- «Производители» → `#manufacturers`
- «Контакты» → `/contacts/`

### 1б. Футер — убрать «Полезное»

Удалить ссылку:

```html
<a href="/articles/" ...>Полезное</a>
```

Она встречается **дважды** — в десктопной и мобильной версиях футера. Удалить обе.

### 1в. Футер — добавить «О компании»

В ту же колонку, где «Оптовым покупателям», «Отзывы», «Прайс-листы», добавить первой строкой:

```html
<a href="/about/" style="[тот же style, что у соседних ссылок колонки]">О компании</a>
```

Так же дважды — десктоп и мобильная версия.

## Изменение 2 — `catalog-listing-gerbicidy.dc.html` (листинг)

Заменить содержимое `<nav>` в шапке. Было:

```html
<a href="/catalog/">Каталог</a>
<a href="/about/">О компании</a>
<a href="/articles/">Полезное</a>
<a href="/contacts/">Контакты</a>
```

Стало — мегаменю каталога первым пунктом, затем четыре ссылки:

```html
<!-- Каталог с мегаменю — перенести блок из Hero.dc.html целиком,
     включая состояние открытия/закрытия по наведению -->
<div style="position:relative;" onMouseEnter="{{ openCat }}" onMouseLeave="{{ closeCat }}">
  ... мегаменю: 7 категорий + 3 входа ...
</div>
<a href="/#tasks">Задачи защиты</a>
<a href="/#how-we-work">Как мы работаем</a>
<a href="/#manufacturers">Производители</a>
<a href="/contacts/">Контакты</a>
```

В data section добавить состояние мегаменю (`catOpen`, `openCat`, `closeCat` — по образцу Hero).

**Телефоны:** одиночную ссылку `+7 (351) 750-09-20` заменить на блок из двух телефонов, как на главной (директорский крупнее, офисный ниже с подписью «офис»).

## Что НЕ меняем

- Визуальный стиль шапки: кремовый фон `#F8F4E9`, нижняя граница `rgba(38,84,62,0.10)`, sticky-поведение, логотип «Восток·АгроХим» с амбровой точкой
- Структуру и содержимое футеров (кроме «Полезное» → удалить и «О компании» → добавить на главной)
- Мобильное поведение шапки (бургер / скрытие `navDisplay`) — логика остаётся прежней, меняется только состав пунктов
- Хлебные крошки, контент страниц, модалку заявки

---

## Проверка после правки

1. Шапки трёх страниц совпадают по составу и порядку пунктов
2. Мегаменю раскрывается на всех трёх страницах и ведёт на одни и те же URL
3. Слова «Полезное» нет ни в одном из трёх файлов
4. «О компании» есть в футере главной и отсутствует в шапках
5. На листинге и карточке якорные пункты ведут на `/#…`, на главной — на `#…`
6. Оба телефона показаны на всех трёх страницах

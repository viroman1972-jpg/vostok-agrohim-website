**Дата прогона:** 12 августа 2026
**Источник:** vostok-agrohim.ru (на платформе satom.ru)
**Скрипт:** `scripts/parser_v2.py` + `scripts/run_smoke.py` (модифицированный для полного прогона с Playwright CDP + real Chrome + resume)
**Результат:** 92/92 SKU распаршены, 0 ошибок парсинга

## Схема JSON-файла карточки

Каждый файл `<slug>.json` содержит следующую структуру (source: `window.__INITIAL_STATE__.page` со страницы):

```json
{
  "source_url": "https://vostok-agrohim.ru/p/v45626617-...",
  "name": "Балерина, СЭ (410 г/л + 7,4 г/л)",
  "satom_id": 45155542,
  "satom_vid": "v45626617",
  "vendor": "Август",
  "price": {"amount": 812, "currency": "RUR", "unit": "л", "raw": "812 ₽/л"},
  "presence": 1, "presence_text": "в наличии",
  "min_order": 1, "quantity": ...,
  "photos": [
    {
      "id": ..., "alt": "...",
      "thumbnail": "...", "middle": "...", "source": "...", "big": "...", "original": "...",
      "width": ..., "height": ...
    }
  ],
  "photos_downloaded": [
    {"photo_idx": 0, "size": "big", "url": "...", "path": "photos/...", "status": "downloaded", "bytes": ...}
  ],
  "attrs": {
    "main":      {"title": "Характеристики", "pairs": [{"key": "...", "value": "..."}]},
    "packaging": {"title": "Размеры упаковки", "pairs": [...]}
  },
  "description": {
    "html": "<div>...</div>",   // сохранённая HTML-структура описания
    "text": "...",              // плейнтекст с сохранением абзацев
    "length_chars": 15481
  },
  "meta": {"title": "...", "description": "...", "keywords": "...", "og:image": "...", ...},
  "breadcrumbs": [{"name": "...", "url": "..."}],
  "category_path_ids": [4015, ...],
  "seo_tags": [{"name": "Магнум", "url": "..."}, ...],    // блок «Смотрите также»
  "related_goods": [{"name": "Альбит, ТПС", "url": "...", "id": 310882, "price": ...}],
  "similar_goods": [],
  "microdata_jsonld": {...},   // Schema.org разметка со страницы
  "_flags": ["no_related_goods", "probable_ai_preamble", ...],
  "category_local": "герб"     // наш локальный тег категории
}
```

## Диагностические флаги (`_flags`)

| Флаг                        | Что значит                                                       | Затронуто SKU |
|-----------------------------|------------------------------------------------------------------|---------------|
| `no_related_goods`          | Блок сопутствующих товаров пуст (нет ручных связок)              | 89/92         |
| `no_seo_tags`               | Блок «Смотрите также» пуст                                       | 16/92         |
| `probable_ai_preamble`      | Обнаружен маркетинговый ИИ-текст в начале описания              | 1/92 (Балерина) |
| `photo_dl_failed_*`         | Не удалось скачать фото (403 или сетевая ошибка)                 | 0             |
| `short_or_no_description`   | Описание короче 100 симв или отсутствует                        | 0             |

## Ключевые выводы для проекта

1. **ОВ32 закрывается.** Массовый анализ показал, что сопутствующие товары настроены на старом сайте только у 3 SKU из 92 (Балерина 2, Эскудо 1, ещё 1). Массового источника связок нет — данные для ДМ29 генерируются алгоритмически.

2. **AI-preamble — локальная проблема Балерины.** Остальные 91 карточка содержат чистый оригинальный контент август.com. Массовой очистки не требуется.

3. **Фотоматериал.** 117 уникальных фото упаковок скачаны, все 100% успешно. Размер `big` (~1024x) и `source` (~800x) — обе версии сохранены.

4. **Юридически значимые поля** (регистрация, ДВ, класс опасности, регламент) в `attrs.main.pairs` — источник **данных старого сайта**, но приоритет отдаётся госреестру (Принцип 4, ПИ10).

5. **Данные для повторного аудита.** `raw_html/` содержит исходный HTML каждой страницы — можно перепарсить без повторного захода на сайт (важно, т.к. anti-bot satom.ru блокирует).

## Как использовать

**Для конкретной SKU:**
```bash
unzip -p parsed_v2_full.zip parsed_v2/balerina-se-410-g-l-7-4-g-l.json | jq .
```

**Массовая выгрузка всех цен:**
```bash
unzip -p parsed_v2_full.zip 'parsed_v2/*.json' | jq -s 'map({name, price: .price.amount})' > prices.json
```

**Извлечь фото Балерины:**
```bash
unzip parsed_v2_full.zip 'parsed_v2/photos/balerina*'
```

## Ограничения парса

- **Anti-bot прошёл только один способ:** реальный Chrome через CDP на локальном IP. Все остальные (requests, curl_cffi, headless Playwright, GHA, Colab) не проходят security-check JS-challenge + reCAPTCHA v3 satom.ru.
- **Cross-sell (relatedGoods).** Присутствует только в `product.relatedGoods.items` state-объекте страницы. На старом сайте настроен только у 3 SKU.
- **Комментарии/отзывы.** Не парсились (по решению 12.08 — на карточках товара их нет, только по компании в целом).

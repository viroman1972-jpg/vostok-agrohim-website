Итого записей: **56 ДВ пестицидов + 2 антидота (сафенера) + 2 биопрепарата/агрохимиката + 4 ПАВ = 64**.

---

## Принципы нормализации (согласовано)

1. **Соли ДВ** — canonical без соли. Соль (калиевая / изопропиламинная / натриевая / диметиламинная и т.п.) — атрибут карточки продукта в поле «Форма соли», не отдельный тег фильтра. Актуально для **глифосата** и **МЦПА**.

2. **Антидоты (сафенеры)** — не входят в основной фильтр «Действующее вещество». Отображаются в составе на карточке товара. Отдельный булевый флаг «с антидотом / без антидота» — **ОВ22**, решить позднее.

3. **Смеси ДВ (комбинированные препараты)** — продукт помечается тегом каждого ДВ из смеси отдельно (многозначный тег). Фильтр «Флорасулам» покажет Балерину, Балерину Форте, Балерину Супер и Ламбаду.

4. **Коды механизма действия (МДА)** — заполнены сразу: HRAC для гербицидов, FRAC для фунгицидов, IRAC для инсектицидов. Основа для будущей вкладки «Ротация препаратов против резистентности».

5. **Регистр канонического имени** — с прописной буквы. Стереоизомерные обозначения («П», «С», «λ», «α») сохраняются в кириллице там, где так пишет Госкаталог (например, «феноксапроп-П-этил», не «феноксапроп-P-этил»). Латинские написания уходят в поле синонимов для поисковой устойчивости.

6. **Тип препарата** — может быть множественным (тебуконазол = фунгицид + протравитель; имидаклоприд = инсектицид + протравитель).

## Синонимы для поисковой устойчивости

Полное соответствие латинскому написанию — в колонке синонимов финального YAML/CSV, когда словарь пойдёт в Tilda. В этой markdown-версии приведены только критичные варианты, где были опечатки или альтернативы:

- **Галоксифоп-П-метил** — вариант написания «галоксифоп-P-метил» (лат. P). Ошибочный вариант в выгрузке — «-Р-метил» (кириллическая Р). Все три отправляют на канон DV006.
- **Феноксапроп-П-этил, Квизалофоп-П-тефурил, Хизалофоп-П-этил** — латинский вариант «P» в поиске работает; кириллица «П» — канон.
- **Тирам** — принимает синонимы «ТМТД», «TMTD», «тетраметилтиурамдисульфид».
- **Меди хлорокись** — принимает синоним «Хлорокись меди».
- **Малатион** — принимает синоним «Карбофос» (устар. торговое название).
- **С-Метолахлор** — принимает «S-metolachlor», «метолахлор» (S-энантиомер).

Латинские написания всех 56 ДВ будут добавлены в v1.1 при экспорте в CSV.

- **ОВ22** (новый): нужен ли отдельный булевый фильтр «с антидотом / без антидота» в каталоге? Затрагивает 5 продуктов (все злаковые гербициды с феноксапроп-П-этил и клодинафоп-пропаргилом). Аргумент за: агроном может искать более безопасную для культуры формулу. Аргумент против: усложнение фильтра ради малого числа SKU.

- **ОВ23** (новый): «акарицид» — отдельный тип препарата или тег на инсектициде? Затрагивает DV009 Диметоат и DV024 Малатион. Рекомендация — **тег** «Акарицидное действие» на карточке, не отдельный тип препарата (иначе появится пустая категория из 2 SKU).

- **Пенцикурон / FRAC 20** — точный код механизма действия требует сверки с актуальной классификацией FRAC. Не блокирует публикацию словаря, уточнить в v1.1.

- **Соли МЦПА в П22 Горгон** — в snapshot указано «МЦПА + Пиклорам 350+150 г/л», без уточнения состава солей. Уточнить при доступе к этикетке или в справочнике Минсельхоза.

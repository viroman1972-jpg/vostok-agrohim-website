# Слаги словарей каталога — v1

**Дата:** 17.08.2026
**Назначение:** адреса страниц параллельных входов в каталог (ДМ02, ДМ26) и поле для импорта разделов в Tilda.
**Охват:** 184 значения — 52 культуры, 68 вредных объектов, 64 действующих вещества.

**Где используются:**

```
/catalog/kultura/{slug}/          — вход по культуре (§6.2 catalog-ia)
/catalog/vrednyy-obekt/{slug}/    — вход по вредному объекту (§6.3)
/catalog/dv/{slug}/               — вход по действующему веществу (§6.4)
```

Сколько из этих значений получит собственную страницу с читаемым адресом, а сколько останется фильтром — решается после проверки механики разделов Tilda (задача `phase-5-tilda/task-catalog-sections-test.md`, ОВ36). Слаги нужны в любом случае: при разделах каталога они задаются в настройках раздела, при ручных посадочных — в адресе страницы.

## Правило транслитерации

Кириллица → латиница по таблице ниже, затем всё, кроме `a–z`, `0–9` и дефиса, заменяется на дефис; повторные дефисы схлопываются, крайние отбрасываются. Регистр приводится к нижнему. Содержимое круглых скобок отбрасывается вместе со скобками.

| Буква | Латиница | Буква | Латиница | Буква | Латиница |
|---|---|---|---|---|---|
| а | a | к | k | х | h |
| б | b | л | l | ц | ts |
| в | v | м | m | ч | ch |
| г | g | н | n | ш | sh |
| д | d | о | o | щ | sch |
| е, ё | e | п | p | ъ, ь | *(опускается)* |
| ж | zh | р | r | ы | y |
| з | z | с | s | э | e |
| и | i | т | t | ю | yu |
| й | y | у | u | я | ya |
| | | ф | f | | |

**Почему не ГОСТ 7.79 и не ISO 9.** Строгие стандарты дают диакритику и сочетания вида `ë`, `ŝ`, `č`, непригодные для URL, либо громоздкие `shh` для «щ». Здесь взят практический вариант, распространённый в рунете: короткие, читаемые адреса, узнаваемые для русскоязычного пользователя. Поисковики не требуют соответствия стандарту — им важна стабильность адреса.

**Исключение — аббревиатуры.** Побуквенная транслитерация аббревиатур даёт бессмыслицу, поэтому они записываются общепринятым латинским эквивалентом:

| Значение | Автоматически | Принято | Причина |
|---|---|---|---|
| МЦПА (DV030) | `mtspa` | **`mcpa`** | Международное обозначение действующего вещества — MCPA |

Других аббревиатур в словарях нет. При пополнении словарей правило применяется по тому же принципу.

## Проверки

| Что проверено | Результат |
|---|---|
| Коллизии — два значения с одинаковым слагом | **нет** во всех трёх словарях и между ними |
| Длина слага | максимум 44 символа, все в пределах разумного |
| Недопустимые символы | нет — только `a–z`, `0–9`, дефис |
| Совпадение количества со словарями | 52 / 68 / 64 — сходится |

Слаги уникальны в пределах всего каталога, а не только внутри своего словаря. Это даёт запас: если позже понадобится плоская схема адресов без префикса раздела, конфликтов не возникнет.

## Правила использования

1. **Слаг неизменен после публикации.** Если значение словаря переименовано, слаг остаётся прежним — иначе теряется накопленный вес страницы и ломаются внешние ссылки. Смена слага допустима только с 301-редиректом (ОВ16).
2. **Новые значения словаря** получают слаг по тому же правилу, с обязательной проверкой на коллизию по всем трём словарям.
3. **Пустые значения** (без единого препарата) страниц не получают, даже если слаг сгенерирован.

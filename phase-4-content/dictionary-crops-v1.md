## Принципы формирования (согласовано ранее)

1. **Иерархия форм культуры** — для пшеницы, ячменя, ржи, тритикале, рапса вводятся родитель + дочерние значения по сезонности («Пшеница» → «Пшеница озимая» / «Пшеница яровая»). Причина: часть регистраций даётся обобщённо на «пшеницу», часть — только на озимую или только на яровую. Плоский словарь теряет разницу, полностью раздельный — теряет обобщённые регистрации.

2. **Механика фильтра:**
   - Клик по родителю («Пшеница») = OR по родителю + всем детям.
   - Клик по ребёнку («Пшеница озимая») = продукты с этим тегом + продукты с тегом родителя.

3. **Тегирование продукта:**
   - Если этикетка говорит «Пшеница озимая и яровая» — тег родителя (C001).
   - Если этикетка говорит только «Пшеница озимая» — тег ребёнка (C002).

4. **На карточке товара** — регистрационная формулировка приводится дословно из Госкаталога («Пшеница озимая и яровая»); теги проставляются по факту регистрации.

5. **Специальные объекты** — «Пар», «Земли несельхозпользования» — записаны в словарь культур как объекты применения, потому что так они указаны в графе «Культура/объект» на этикетках.

6. **Атрибуты, не влияющие на иерархию:**
   - **Устойчивые к имидазолинонам гибриды** («Clearfield», «Express Sun») — не отдельная культура, а атрибут карточки продукта. Рекомендация — **ОВ25** ниже.
   - **Ботанические разновидности внутри одной культуры** (капуста белокочанная / краснокочанная / цветная) — не расписываются в v1, «капуста» = зонтичное значение.

## Приоритизация в UI фильтра

Профиль клиентов Восток АгроХим — крупные хозяйства Челябинской области и соседних регионов Урала. Основные культуры региона — пшеница яровая, ячмень яровой, овёс, картофель, подсолнечник, рапс яровой, гречиха, многолетние травы.

**Рекомендация для UI:** в фильтре «Культура» показывать раскрытыми группы «Зерновые колосовые» и «Технические масличные» (top-of-mind для клиентов). Группы «Овощные», «Плодовые» — под «Ещё» / свернуты. Порядок групп в фильтре по частоте использования, а не по алфавиту.

Финальный порядок групп предлагаю такой:

1. Зерновые колосовые
2. Зерновые прочие
3. Технические масличные
4. Свёкла сахарная (объединить с «Технические масличные» в UI, чтобы не было группы из одного элемента)
5. Зернобобовые
6. Кормовые + Кормовые угодья (объединить в UI)
7. Овощные
8. Плодовые
9. Спец. объекты

## Открытые вопросы

- **ОВ24** (новый): лён-долгунец и лён масличный — оставить раздельно (как сейчас) или объединить в «Лён» с атрибутом «долгунец/масличный» на карточке? Регистрационно на этикетках почти всегда указывается конкретная форма (у них разные регламенты, разная агротехника). Рекомендация — **оставить раздельно**.

- **ОВ25** (новый): устойчивые к имидазолинонам гибриды подсолнечника и рапса (Clearfield, Express Sun) — как оформить в каталоге? Три варианта:
  - (а) отдельная культура «Подсолнечник Clearfield» / «Рапс Clearfield»,
  - (б) атрибут карточки продукта («технология: Clearfield / Express Sun»),
  - (в) тег на карточке в описании регламента.
  Рекомендация — **вариант (б)**: атрибут на карточке продукта, потому что затрагивает только 2 продукта (П4 Грейдер, П80 Евро-Ленд) и не является культурой ботанически.

- **ОВ26** (новый): нужны ли в словаре «клубника/земляника», «смородина», «крыжовник», «плодовые косточковые» (вишня, слива)? По каталогу Августа (agroxxi) для меди хлорокиси, тебуконазола есть регистрации на эти культуры, но фактических продаж в Челябинской области ~0. Рекомендация — **в v1 не включать**; добавить в v2 если понадобится по спросу.

- **Верификация покрытия культур для каждого продукта** — отдельная задача. Мне понадобится либо доступ к сводной таблице этикеток из финального Excel верификации (лист «Каталог_норм»), либо разметка вручную из agroxxi по каждому продукту. Уточни, что доступно.

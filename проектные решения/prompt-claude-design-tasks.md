# Промпт для Claude Design — Блок «Задачи защиты»

## Контекст

Сайт ООО «Восток АгроХим» — региональный поставщик СЗР (Челябинск). Официальный дилер АО Фирма «Август». Основные покупатели — сельхозпроизводители, КФХ, дистрибьюторы; в меньшей мере — розница/дача.

Идёт Phase 3. Hero-блок принят в v5 (`phase-3-design/blocks/hero/`). Сейчас — блок «Задачи защиты», третий содержательный блок главной по `homepage-structure-v2.md` v2.2 (после «Как мы работаем», перед «Каталог»).

*Примечание для контекста: в более ранней версии структуры между Hero и «Как мы работаем» был блок «Для кого мы работаем» с сегментацией опт/дача. С 19.07.2026 клиент отказался от работы с аудиторией дачников (решение НР01), сегментация на главной снята, аудитория одна — профессиональный B2B (агрономы, КФХ, оптовые покупатели). Поэтому «Задачи защиты» теперь третий блок, а не четвёртый.*

## Назначение

Быстрый ярлык в каталог для того, кто уже знает свою проблему. Типовой пользователь — глава КФХ 350 га, пришёл с конкретной задачей («лезет овсюг»), хочет быстро дойти до нужной группы препаратов. Расширенный поиск (по культуре, производителю, действующему веществу) — через мостик снизу, не в плитках.

## Иконки

Строгие однотонные линейные пиктограммы (line-art). Референс — знаки на этикетках СЗР, ГОСТ-схемы: скупая линия, узнаваемый силуэт, один цвет.

Мотивы (guideline, окончательно уточняет дизайнер):

- Сорняки: колос со сорной травой рядом
- Болезни: лист с пятном / грибковой формой
- Вредители: силуэт жука
- Другие задачи: канистра с каплей или обобщённый значок

Цвет иконки: амбр `#E4A853` или тёмно-зелёный `#1B4332` — что лучше читается на выбранном фоне плитки.

Не использовать: цветные иллюстрации, 3D, emoji, стоковые фото, мультяшные образы.

## Layout

### Desktop 1440

- Full-width секция на фоне `#F8F4E9`
- Контейнер до 1200px, центрирован
- Вертикальный padding консистентно с Hero
- H2 крупный, выравнивание на усмотрение дизайнера (по центру или слева)
- 4 плитки в один ряд, равной ширины, с ощутимым воздухом между
- Плитка: чуть светлее фона или белая, мягкая рамка/тень; вертикальный поток внутри — иконка → заголовок → тип препарата → якорь
- Мостик — под плитками с ощутимым воздухом, ключевая ссылка **«Все входы в каталог →»** выделена амбром

### Mobile 375

- Плитки в столбец (или сетка 2×2 — на выбор дизайнера, что дышит лучше)
- Иконки уменьшены; текст без мельчания
- H2 — 28–32px
- Мостик — той же формулировкой, ссылка полной строкой

## Interactivity

- Hover на плитке (desktop): усиление тени + переход рамки/фона на тёплый оттенок, `cursor: pointer`
- Tap (mobile): активное состояние с лёгким затемнением
- Focus (клавиатура): контурная рамка для accessibility
- Мостик-ссылка: стандартный hover с изменением цвета/подчёркиванием

## Deliverables

- Один HTML-файл со встроенным CSS (по образцу Hero), self-contained
- Desktop 1440 + Mobile 375 в одном файле через `@media` или отдельные секции — по паттерну Hero
- Шрифты через Google Fonts (как в Hero)
- Иконки — inline SVG (не `<img>`), чтобы менять цвет через `currentColor`
- Ссылки — реальные пути (не `#`), даже если целевые страницы ещё не собраны

## Что учесть на основе Hero

- Соблюдать общий вертикальный ритм и типографическую иерархию, установленную в Hero
- Не вводить новых семейств шрифтов
- Не вводить новых цветов вне палитры
- Внутренние отступы плиток — визуально согласованы с блоками контента в Hero

## Что не делать

- Никаких форм, полей ввода или поиска — этот блок это визитка задач
- Никаких логотипов производителей — они в блоке «Производители» ниже
- Никаких фото продукции внутри плиток
- Никаких счётчиков «X препаратов в этой категории» — данные не финализированы

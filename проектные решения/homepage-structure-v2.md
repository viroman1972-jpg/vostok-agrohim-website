# Homepage Strategy

The homepage should present Vostok-AgroHim as an expert regional supplier of crop protection products.

The website should not look like:
- an online store;
- a large anonymous distributor;
- a marketplace.

The main value proposition:

"Подбираем решения для защиты урожая, а не просто продаём препараты."

Homepage logic (v2.11+):

Trust (Hero) → Positioning (Company Expertise) → Solution (Задачи защиты) → Product (Каталог) → Trust reinforcement (Производители) → **Contact (Как мы работаем + CTA)** → Reference (Footer)

Шесть содержательных блоков вместо семи. Устранено дублирование между отдельным блоком «Как мы работаем» и отдельным Final CTA.

Как мы работаем · Задачи защиты · Каталог ▾ · Производители · Контакты

# 6. Как мы работаем + CTA (объединённый, v2.11 — ДМ22; уточнён в v2.13)

## Purpose

Блок отвечает на два вопроса одновременно: (а) «а как это будет происходить» — процесс работы в трёх этапах; (б) «что мне делать сейчас» — прямой призыв к контакту.

## Часть 1 — Процесс (v2.6 без изменений)

### Лейбл

КАК МЫ РАБОТАЕМ (с короткой амбровой линией слева, uppercase 13px letter-spacing 0.1em, цвет `#26543E`)

### Main message (H2)

Подбираем решения для защиты растений, а не просто продаём препараты

### Supporting text (sub, ДМ15)

От заявки до отгрузки — три этапа:

### Three stages

- **01. Анализируем задачу** — Выясняем, с чем столкнулось хозяйство и на какой стадии.
- **02. Подбираем решение** — Готовим предложение по препаратам и схеме внесения.
- **03. Организуем поставку** — Отгружаем продукцию с документами и сопровождаем заказ.

### Format (ДМ15)

Три колонки на десктопе, стопкой на мобильном. В каждой: крупная амбровая цифра (Merriweather Bold ~34/28px), короткий заголовок (Merriweather Bold ~22/19px), одна связная строка описания (Inter ~16/15px, `#4A4D4E`). Белый фон.

## Часть 2 — Кнопки (v2.13, без переходной строки)

Под тремя этапами — сразу две кнопки, без промежуточной подводки. В версиях v2.11–v2.12 между этапами и кнопками была строка «Расскажите о задаче.» — в v2.13 она убрана по указанию заказчика: три этапа сами по себе служат достаточной подводкой к кнопкам.

### Кнопки

**Primary — «Получить консультацию»:** заливка `#E4A853`, текст `#1A1D1F`, bold. Действие: открытие модала с conversational form (**ДМ21**). Тот же модал открывается по CTA в Hero и в блоке 3.

**Secondary — «Позвонить нам»:** обводка `#26543E`, текст `#26543E`, прозрачный фон. Действие: `tel:+73517500920`.

Промпт: `проектные решения/prompt-claude-design-how-we-work-cta.md`.

# Final Design Principles

The website should communicate: expertise; reliability; personal involvement; practical agricultural knowledge.

The website should avoid: exaggerated scale claims; unsupported partnership claims; marketplace style; price-driven communication.

Core customer feeling: "Этой компании можно доверить задачу защиты урожая."

# Homepage Strategy

The homepage should present Vostok-AgroHim as an expert regional supplier of crop protection products.

The website should not look like:
- an online store;
- a large anonymous distributor;
- a marketplace.

The main value proposition:

"Подбираем решения для защиты урожая, а не просто продаём препараты."

Homepage logic (v2.11):

Trust (Hero) → Positioning (Company Expertise) → Solution (Задачи защиты) → Product (Каталог) → Trust reinforcement (Производители) → **Contact (Как мы работаем + CTA)** → Reference (Footer)

Ключевая идея: клиент сначала убеждается, что пришёл в правильное место (Positioning), потом идёт к своей задаче и продукту (Solution → Product), потом получает финальное подтверждение доверия через ключевого партнёра АО «Август» (Trust reinforcement). Только после этого видит процесс работы (Как мы работаем) и здесь же — приглашение сделать первый шаг: две кнопки — заявка через conversational form (ДМ21) или звонок в офис. Footer завершает страницу справочной информацией.

Шесть содержательных блоков вместо семи. Устранено дублирование между отдельным блоком «Как мы работаем» (описание процесса) и отдельным Final CTA (приглашение к контакту) — они объединены в один блок Contact.

С 2011 года помогаем защищать урожай.

## Format (ДМ13)

**Компактный список из пяти коротких строк на кремовом фоне** (`#F8F4E9`). Амбровый маркер слева от каждой строки. Нет плиток, карточек, иконок, нумерации 01–05, заголовков внутри пунктов.

## Five points (утверждённые формулировки, 22.07.2026)

- Подберём препараты под вашу задачу

- Подскажем нормы расхода и баковые смеси
- Отпустим и одну упаковку, и оптовую партию
- Обсудим цену индивидуально — зависит от объёма заказа

## What this block does not do

- No CTA button, no links inside the points
- No hover interactions
- No explicit mention of "agronom"

# 6. Как мы работаем + CTA (объединённый, v2.11 — ДМ22)

## Purpose

Блок отвечает на два вопроса одновременно: (а) «а как это будет происходить» — процесс работы в трёх этапах; (б) «что мне делать сейчас» — прямой призыв к контакту. Ранее это были два разных блока (5 «Как мы работаем» + 7 «Final CTA»); в v2.11 они объединены — три этапа процесса естественно завершаются приглашением сделать первый шаг.

Блок работает как **финальная точка выбора**: клиент видит процесс, получает переход и две кнопки — заявка через conversational form (ДМ21) или звонок в офис.

## Часть 1 — Процесс (v2.6 без изменений)

### Лейбл

КАК МЫ РАБОТАЕМ (с короткой амбровой линией слева, uppercase 13px letter-spacing 0.1em, цвет `#26543E` — по ДМ20)

### Main message (H2)

Подбираем решения для защиты растений, а не просто продаём препараты

### Supporting text (sub, ДМ15)

От заявки до отгрузки — три этапа:

### Three stages (утверждённые формулировки, 22.07.2026)

- **01. Анализируем задачу** — Выясняем, с чем столкнулось хозяйство и на какой стадии.
- **02. Подбираем решение** — Готовим предложение по препаратам и схеме внесения.
- **03. Организуем поставку** — Отгружаем продукцию с документами и сопровождаем заказ.

### Format (ДМ15)

**Компактный формат: три колонки без плиточных фонов и бордюров** на десктопе; стопкой на мобильном. В каждой колонке:

- Крупная амбровая цифра сверху (01/02/03, `#E4A853`, Merriweather Bold ~34px десктоп / 28px мобильный)
- Короткий заголовок этапа (Merriweather Bold, ~22px десктоп / 19px мобильный)
- **Одна связная строка описания** (Inter, ~16px десктоп / 15px мобильный, цвет `#4A4D4E`)

Блок на белом фоне (не кремовом — кремовый остаётся только у Company Expertise; не тёмно-зелёном — тёмно-зелёный остаётся только у футера).

## Часть 2 — Переход + кнопки (v2.11, новое)

### Переход

**Расскажите о задаче.**

Одна строка, центрирована, Merriweather Bold или Inter Semibold, ~22-26px десктоп / 18-20px мобильный, цвет `#1A1D1F` (тёмный). Точка на конце — утверждение, не восклицание.

### Кнопки

**Primary — «Получить консультацию»:**
- Заливка амбровым `#E4A853`
- Текст `#1A1D1F` (тёмный)
- Bold weight, высота ~48-56px, padding ~32-40px
- **Действие:** открытие модала с conversational form (**ДМ21**) — форма заявки в чат-подобном формате, вопросы задаются последовательно один за другим. Это НЕ live-chat со специалистом; сценарий предопределён, ответы собираются пошагово (аналогично боту). Поля по ДМ03: тип клиента (ЮЛ / ИП / КФХ / самозанятый / физлицо) как tap-кнопки, имя, телефон, задача, согласие ПД. Реализация — при вёрстке в Tilda.
- **Тот же модал** открывается по CTA «Получить консультацию» в Hero и по CTA «Подобрать решение для вашей задачи» в блоке 3 «Задачи защиты» — единый механизм заявок на всей главной.

**Secondary — «Позвонить нам»:**
- Обводка тёмно-зелёным `#26543E` (1-2px, аутлайн)
- Текст `#26543E`, фон прозрачный
- Высота такая же, как у primary
- Действие: `tel:+73517500920` (телефон офиса)

## What this block does not do

- No aggressive sales communication, no marketplace style
- No plate backgrounds or borders around stages
- No inline form in the block — форма открывается модалом
- No отдельный тёмно-зелёный CTA-блок ниже — объединение упраздняет его
- No декоративные элементы, восклицательные знаки, срочность, дефицит

Промпт: `проектные решения/prompt-claude-design-how-we-work-cta.md`. Устаревший промпт `prompt-claude-design-final-cta.md` помечен deprecated.

# Final Design Principles

The website should communicate: expertise; reliability; personal involvement; practical agricultural knowledge.

The website should avoid: exaggerated scale claims; unsupported partnership claims; marketplace style; price-driven communication.

Core customer feeling: "Этой компании можно доверить задачу защиты урожая."

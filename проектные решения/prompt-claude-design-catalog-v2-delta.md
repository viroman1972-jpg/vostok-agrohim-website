# Дельта к промпту «Каталог» — v2

## Контекст

Блок «Каталог» доставлен в `Hero.dc.html` (накопительный файл). Плейсхолдер-паттерн реализован как штриховка + линейный силуэт упаковки поверх. Штриховка и амбровый прямоугольник-этикетка приняты. **Меняем только силуэт упаковки.**

## Что меняем

Текущий силуэт читается как медицинский флакон / склянка (вертикальный корпус с центральным горлышком и петлёй-крышкой сверху). Для агрономической аудитории узнаваемая форма упаковки СЗР — **пластиковая канистра 5–10 л с интегрированной боковой ручкой**. Разница нюансная, но узнавание должно быть мгновенным.

## Целевой образ

Стандартная плоская пластиковая канистра для агрохимии:

- Прямоугольный корпус вертикальной ориентации, чуть шире, чем текущий флакон
- Скошенное левое плечо (небольшая диагональ сверху слева вниз к горловине)
- Короткое цилиндрическое горлышко с крышкой — **на левом верхнем углу**, не по центру
- **Встроенная ручка** — каплевидный или овальный вырез в правой верхней части корпуса, внутри контура (не отдельная приделанная ручка, а вырез-петля в теле канистры)
- Амбровый прямоугольник-этикетка `#E4A853` — по центру передней грани канистры, тех же пропорций, что сейчас (стоящий прямоугольник, ~половина ширины корпуса, ~треть высоты)

Line-art язык — тот же: `stroke="currentColor"`, `stroke-width` в диапазоне текущего, `stroke-linecap="round"`, `stroke-linejoin="round"`. Никакой заливки корпуса, никаких градиентов, никакого 3D.

## Где менять

Два места в `Hero.dc.html`, идентичный SVG-код в обоих:

- **Desktop catalog** — секция `<!-- catalog desktop -->`, блок с классом-эквивалентом «thumb» внутри карточки товара. SVG `88×104` (размер отображения) поверх штриховки.
- **Mobile catalog** — секция `<!-- catalog mobile -->`. SVG `76×90` (размер отображения), тот же viewBox `88 104`.

Один и тот же SVG-исходник, отличается только display width/height.

## Что оставить как есть

- viewBox `0 0 88 104`
- Штриховка карточки (`repeating-linear-gradient(135deg, ...)`) — не трогать
- Амбровый прямоугольник-этикетка `stroke="#E4A853"` — сохранить, вписать в новую форму по центру передней грани
- Размеры слота карточки (aspect-ratio 1:1) и размеры отображения SVG на десктопе/мобайле — те же
- Всё остальное содержимое карточки (название, производитель, назначение, «Подробнее →») — не трогать

## Что не делать

- Не превращать line-art в реалистичное 3D-изображение канистры
- Не добавлять внутри SVG текст (литраж, «5L», логотипы) — этикетка чисто графическая
- Не менять цвета корпуса и штриховки (`currentColor` на корпусе, `#E4A853` только на этикетке)
- Не рисовать канистру с отдельно приделанной пластиковой ручкой сбоку — только встроенный вырез-петля
- Не делать канистру подчёркнуто «мультяшной» или технически-детализированной (винтовая резьба на крышке, риски, тени) — язык остаётся скупым и знаковым

# Промпт для Claude Design — Блок «Каталог», микро-правка v4-delta

Одна правка к принятой версии блока «Каталог» v11. Ничего кроме описанного ниже не трогаем.

---

## Задача. Исправить состав в описании Ордана

В объекте данных `products` третьей карточки (Ордан) исправить описание. Текущая формулировка содержит фактическую ошибку — «Цимоксанил + манкоцеб» относится к другому препарату (Ордан МЦ), а не к Ордану (СП).

Реальный состав Ордана (СП): меди хлорокись 689 г/кг + цимоксанил 42 г/кг — что подтверждается официальным источником АО Фирма «Август» и совпадает с этикеткой на изображении в карточке.

### Текущая строка

```javascript
{ name: "Ордан", maker: "АО Фирма «Август»", type: "Фунгицид", desc: "Фитофтороз, альтернариоз и другие болезни картофеля, томата, огурца, лука. Цимоксанил + манкоцеб.", href: "/catalog/ordan", img: "uploads/prod-ordan-fit.png" },
```

### Новая строка

```javascript
{ name: "Ордан", maker: "АО Фирма «Август»", type: "Фунгицид", desc: "Фитофтороз, альтернариоз и другие болезни картофеля, томата, огурца, лука. Меди хлорокись + цимоксанил.", href: "/catalog/ordan", img: "uploads/prod-ordan-fit.png" },
```

Меняется только одно предложение в поле `desc`: **«Цимоксанил + манкоцеб.»** → **«Меди хлорокись + цимоксанил.»**

Остальные поля (`name`, `maker`, `type`, `href`, `img`) не трогаем.

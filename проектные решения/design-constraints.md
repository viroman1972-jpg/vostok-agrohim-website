# Design Constraints — Восток-Агрохим

Version: 1.0

## Назначение документа

Этот документ фиксирует ключевые ограничения и принципы дизайна сайта.

Его задача — сохранить единое направление проекта при дальнейшей разработке.

Все дизайнерские решения должны соответствовать этим принципам.

---

# Основное направление бренда

Концепция:

«Уверенная классика»

Характер:

- сдержанность;
- профессионализм;
- надежность;
- деловой тон;
- основательность.

Главное впечатление от сайта:

«Это надежный специалист, с которым спокойно работать».

---

# Позиционирование

Компания не должна выглядеть как:

- крупная федеральная корпорация;
- безличный интернет-магазин;
- рекламный агрохолдинг.

Желаемый образ:

Небольшой региональный эксперт в области средств защиты растений, который хорошо знает продукт и помогает клиентам подобрать решение.

---

# Главный принцип коммуникации

Продавать не только продукт.

Показывать:

- экспертизу;
- понимание задач клиента;
- консультацию;
- надежность сотрудничества.

Ключевая идея:

«Подбираем решения, а не просто продаем препараты».

---

# Визуальный стиль

Использовать:

- спокойный профессиональный B2B-дизайн;
- много воздуха;
- четкую сетку;
- качественную типографику;
- реальные изображения;
- аккуратную подачу продукции.

Предпочтительная палитра:

Основной:
#1B4332 — глубокий зеленый

Фоновый:
#F8F4E9 — теплый кремовый

Акцент:
#E4A853 — янтарный

Текст:
#1A1D1F

---

# Фотография и визуальные материалы

Предпочтительно:

- реальные рабочие процессы;
- продукция;
- склад;
- консультация;
- специалисты.

Для Hero:

Концепция:
человек + продукция.

Ограничения:

- лицо директора не использовать без отдельного согласования;
- не использовать постановочные корпоративные портреты;
- человек может быть показан со спины или без идентификации.

---

# Не использовать

## Визуальные клише:

- трактор на поле;
- человек с колосом в руках;
- стандартные фотографии счастливых фермеров;
- абстрактные поля из фотобанков.

## Коммуникационные клише:

Не использовать:

- «лидер рынка»;
- «номер один»;
- «крупнейший поставщик»;
- неподтвержденные масштабные заявления.

---

# UX-принципы

Порядок убеждения пользователя:

1. Доверие.
2. Понимание подхода компании.
3. Ознакомление с решениями.
4. Выбор продукции.
5. Контакт.

Не начинать сайт с каталога как с интернет-магазина.

---

# Главная эмоциональная цель

После просмотра сайта клиент должен подумать:

«Этим людям можно доверить задачу защиты урожая. Они помогут выбрать подходящее решение».

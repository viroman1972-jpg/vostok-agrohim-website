## Задача. Заменить изображение Борей Нео на корректную версию

Текущее изображение препарата в карточке Борей Нео (файл `uploads/prod-borey.png` и производный `uploads/prod-borey-fit.png`) содержит фактическую ошибку на этикетке: показан состав «имидоклоприда + лямбда-цигалотрина + клотианидина». Это состав ДРУГОГО препарата (обычный Борей, двухкомпонентный, где есть лямбда-цигалотрин + имидаклоприд), а не Борей Нео.

Реальный состав Борей Нео (СК) — трёхкомпонентный:
- 125 г/л альфа-циперметрина
- 100 г/л имидаклоприда  
- 50 г/л клотианидина

Заказчик приложила к этой сессии корректную версию изображения, где состав на этикетке соответствует реальному Борей Нео. Изображение прикреплено как файл — заменить им текущий `uploads/prod-borey.png`, пересобрать производный `uploads/prod-borey-fit.png` по обычной процедуре кадрирования под квадратный контейнер карточки.

## Что не трогать

- Остальные три карточки (Торнадо 540, Ордан, Суховей) — без изменений.
- Все три остальных изображения (`prod-tornado.png`, `prod-ordan.png`, `prod-suhovey.png` и их `-fit` варианты) — без изменений.
- HTML-структура, стили карточек, H2, CTA — без изменений.
- Никакие другие блоки главной страницы — без изменений.

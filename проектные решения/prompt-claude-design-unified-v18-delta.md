# Единый delta-промпт для Claude Design — все накопившиеся правки к Hero.dc.html

Итерация после приёмки макета v17 (24.07.2026). Три группы правок объединены в один промпт: **миграция наименования по всему макету + правки описаний блока «Каталог» + указатель на delta блока «Производители»**.

Все правки основаны на решениях реестра `00-management/decisions-registry.md` от 08.08.2026 (ПИ07, п.1/2/3 директив заказчика + п.4 правок каталога).

---

## Задача A — Миграция наименования компании (глобально по всему Hero.dc.html)

Полная легальная форма применяется **везде**, во всех блоках макета — в текстах, alt-атрибутах, meta-тегах, любых упоминаниях.

### Правило 1. «Восток-Агрохим» → «Восток АгроХим»

Пробел вместо дефиса, заглавная «Х» в «Хим». Основание — данные ЕГРЮЛ (ОГРН 1117447002694, полная форма «ООО «Восток АгроХим»»).

| Было | Стало |
|---|---|
| Восток-Агрохим | Восток АгроХим |
| Восток Агрохим *(если встречается пробел + маленькая х)* | Восток АгроХим |
| ООО «Восток-Агрохим» | ООО «Восток АгроХим» |
| ООО «Восток Агрохим» | ООО «Восток АгроХим» |

**Исключение — стилизованный логотип «Восток·АгроХим»** (с медианной точкой·, ДМ09 — утверждённый wordmark в шапке и футере). Медианную точку оставляем, только капитализируем «Х» в «Хим»:

| Было | Стало |
|---|---|
| Восток·Агрохим | Восток·АгроХим |

Латинскую форму `vostok-agrohim.ru` (домен) и slug'и URL **не трогать**.

### Правило 2. «АО «Август»» → «АО Фирма «Август»»

Полная легальная форма производителя используется во всех упоминаниях: proof-строка Hero, блок «Производители», карточки препаратов в «Каталоге», шапка и тело модалки дилерского письма, любые alt-атрибуты и aria-label.

Работать со всеми типографическими вариантами кавычек, которые могут встретиться:

| Было | Стало |
|---|---|
| АО «Август» *(с французскими кавычками « »)* | АО Фирма «Август» |
| АО „Август" *(с нижней кавычкой „ и любой закрывающей — U+201C, U+201D, ASCII")* | АО Фирма „Август" |
| АО "Август" *(с прямыми ASCII-кавычками)* | АО Фирма "Август" |

Тип кавычек сохраняется, добавляется только «Фирма » между «АО » и «"Август"».

### Что применить (список конкретных мест)

Пройти по всему `Hero.dc.html` и заменить все вхождения по обоим правилам. В том числе:

- Логотип в шапке (текстовая подпись Merriweather Black)
- Логотип в футере (та же подпись)
- Proof-строка Hero — «Официальный дилер АО «Август»…»
- Заголовок модалки дилерского письма «Дилерское письмо АО «Август»…»
- Alt-текст логотипа Августа на лого-плитке в блоке «Производители»
- Юридическая колонка футера — «ООО «Восток-Агрохим»» (если такая форма где-то осталась после макета v17)
- Копирайт в футере — «© 2011–2026 ООО «Восток-Агрохим»»
- Карточки препаратов в блоке «Каталог» — поле `maker` объекта `products` (сейчас `"АО «Август»"`) для всех четырёх карточек
- Meta-теги и любые внутренние атрибуты, если содержат имя компании или производителя

Регресс-чек: `grep` по итоговому файлу не должен показывать ни одного вхождения «Восток-Агрохим» (с дефисом), ни одного «Восток Агрохим» (с маленькой х), ни одного «АО «Август»» без «Фирма ».

## Задача B — Правки описаний карточек в блоке «Каталог»

Утверждены заказчиком. Обновить поле `desc` в объекте `products` для трёх карточек из четырёх (карточка Ордана — без изменений).

### B.1 Торнадо 540 — убрать «десикация посевов»

Текущий `desc` содержит «Однолетние и многолетние сорняки, десикация посевов. Действующее вещество — глифосат, 540 г/л.»

Формулировка про десикацию **запрещена** — Торнадо 540 официально не зарегистрирован для десикации по действующей регистрации. Оставить только гербицидное действие.

**Было:**
```
"Однолетние и многолетние сорняки, десикация посевов. Действующее вещество — глифосат, 540 г/л."
```

**Стало:**
```
"Однолетние и многолетние сорняки. Действующее вещество — глифосат, 540 г/л."
```

Меняется одна фраза внутри `desc`; всё остальное в карточке Торнадо 540 (name, maker, type, href, img) — без изменений.

### B.2 Борей Нео — добавить «и других»

Расширить список культур, чтобы карточка не казалась узкоприменимой. Формулировка утверждена.

**Было:**
```
"…на зерновых, овощных, плодовых культурах…"
```

**Стало:**
```
"…на зерновых, овощных, плодовых и других культурах…"
```

Меняется вставка одного слова; всё остальное в карточке Борей Нео (name, maker, type, href, img) — без изменений.

### B.3 Суховей — новый перечень культур

Расширить перечень культур в соответствии с официальной регистрацией АО Фирма «Август» (подтверждено скриншотом avgust.com от заказчика 08.08.2026: регистрация Суховея включает подсолнечник, картофель, зерновые колосовые культуры, сою; десикация в период созревания при влажности зерна не выше 30%).

**Было** *(в макете v17)*:
```
"Предуборочное подсушивание подсолнечника, сои, рапса, зернобобовых. Дикват, 150 г/л."
```

**Стало:**
```
"Предуборочное подсушивание подсолнечника, сои, рапса, зерновых колосовых, картофеля. Дикват, 150 г/л."
```

Формулировка «зерновые колосовые» — точная терминология из официальной регистрации (не «зерновые» вообще, а именно колосовые: пшеница, ячмень, овёс, рожь). Добавлен картофель по подтверждённой регистрации. Меняется одно предложение внутри `desc`; всё остальное в карточке Суховея — без изменений.

### Что не трогать в блоке «Каталог»

- **Карточка Ордана** — `desc` без изменений (в v11-v13 текущая формулировка «Меди хлорокись + цимоксанил» уже корректна и совпадает с этикеткой)
- H2 «Что чаще всего заказывают»
- CTA «Смотреть каталог»
- Стили карточек, структура, layout, порядок карточек
- Изображения препаратов
- Ссылки `href`
